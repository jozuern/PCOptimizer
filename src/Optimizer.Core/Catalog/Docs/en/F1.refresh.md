# Display refresh rate below its maximum

## Summary
::: status Problem
{{display}} runs at {{current}} Hz, but Windows offers up to {{max}} Hz at this resolution. Games cannot show more frames than the display refreshes.
:::
::: status Ok,Unknown,Info,Unsupported
Checks that each monitor runs at the highest refresh rate Windows offers for its current resolution.
:::

## Why it matters
A monitor shows a new image only at each refresh. At 60 Hz the screen updates every 16.7 ms; at 144 Hz every 6.9 ms. If the monitor is set lower than it can do, frames the graphics card renders above that rate are never shown, motion looks less smooth and the time until a new frame appears on screen is longer. Windows often keeps 60 Hz after a new monitor, a new cable or a driver reinstall, so this is one of the most common misconfigurations on gaming PCs.

## How we detected it
We read the active display paths through the Windows display configuration API (CCD), which reports the exact current rate as a fraction (for example 143.98 Hz). We then list the modes Windows offers for the same resolution and take the highest progressive one. A difference of less than 1 Hz (143.98 vs. 144, 59.94 vs. 60) counts as OK. Each monitor is checked on its own, so a 60 Hz office monitor next to a 144 Hz gaming monitor is not reported.

## How to fix
1. Open **Settings > System > Display > Advanced display** and select {{display}}.
2. Under **Choose a refresh rate**, pick the highest value.
3. If the highest value is missing there, check the GPU control panel (NVIDIA Control Panel > Change resolution, or AMD Software > Display) and make sure the cable supports it: DisplayPort, or HDMI 2.0 or newer for 144 Hz at 1440p.

Or use **Fix** at the top of this panel: the app makes the change for you and can undo it later.

## How to check the fix
Run the scan again. The current rate should equal the highest offered rate. You can also open the monitor's on-screen menu, which usually shows the incoming refresh rate.
