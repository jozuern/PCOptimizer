# Find my device off

## Summary
Stops Windows from regularly sending this PC's location so you can find it in your Microsoft account.

## How it works
The policy "Turn On/Off Find My Device" is set to off [1][2]. On devices with an active pen, the last location where the pen was used is no longer shown [1].

## Why it can help
Less data leaves this PC. No measurable effect on performance.

## Evidence
Privacy setting; it does not change frame rate or latency.

## Trade-offs & risks
You cannot locate or lock this PC remotely if it is lost or stolen.

## When not to use it
On laptops you carry around.
