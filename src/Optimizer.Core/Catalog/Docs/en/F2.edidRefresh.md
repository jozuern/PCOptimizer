# Monitor supports more than Windows offers

## Summary
::: status Problem
{{display}} reports up to {{edidMax}} Hz, but Windows offers at most {{offered}} Hz. The connection or a monitor setting limits it.
:::
::: status Ok
Windows offers the refresh rates that {{display}} reports.
:::
::: status Unknown,Info,Unsupported
Compares the highest refresh rate the monitor reports (EDID) with the highest rate Windows offers for it.
:::

## Why it matters
Windows only offers display modes that the monitor, the cable, both ports and the graphics driver all support. If the monitor's own data says it accepts a much higher rate than any offered mode, one part of that chain is the limit. Each connection type and cable class has a maximum bandwidth; HDMI cables, for example, are certified for a stated bandwidth [2]. At 144 Hz a new image can appear every 6.9 ms, at 60 Hz only every 16.7 ms.

## How we detected it
We read the range limits from the monitor's EDID (the data block every monitor sends) and the list of modes Windows offers for that display at any resolution. Windows also reports the connector type of each display (HDMI, DVI, DisplayPort, VGA or internal) [1]. We report a problem only when the EDID maximum is at least 75 Hz and at least 20 % above the highest offered mode. Some monitors list a slightly higher maximum than they show at full resolution, and some list their highest rates only in an extension block we do not read, so treat this as a strong hint, not as proof.

## How to fix
::: variant hdmi,dvi,vga
1. Connect the monitor with **DisplayPort** if the monitor and the graphics card have it. Older connection types carry less bandwidth and may not reach high refresh rates at high resolutions.
:::
1. Use the cable that came with the monitor or a certified cable for the bandwidth you need (for HDMI 2.1 rates an Ultra High Speed HDMI cable [2]).
1. Open the monitor's own menu and look for settings that limit the input, for example a DisplayPort version set to 1.1, an HDMI mode set to 1.4, or an "Overclock" option that is off.
1. If Windows still does not offer the rate, install the monitor driver (INF file) from the monitor manufacturer.
1. Then choose the rate in **Settings > System > Display > Advanced display**.

## How to check the fix
Run the scan again. Windows should now offer the higher rate, and the refresh rate check shows whether it is selected.
