# Handwriting data sharing off

## Summary
Stops Windows from sending handwriting samples and handwriting recognition error reports to Microsoft.

## How it works
Two policies turn off handwriting personalization data sharing and handwriting recognition error reporting [1].

## Why it can help
Less data leaves this PC. No measurable effect on performance.

## Evidence
Privacy setting; it does not change frame rate or latency.

## Trade-offs & risks
None for users without a pen.

## When not to use it
If you want to help improve handwriting recognition.
