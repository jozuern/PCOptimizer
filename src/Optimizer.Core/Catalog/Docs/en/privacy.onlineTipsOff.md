# Online tips in Settings off

## Summary
Stops the Settings app from loading tips and help content from Microsoft's servers.

## How it works
The policy "Allow Online Tips" is set to off [1].

## Why it can help
Less data leaves this PC. No measurable effect on performance.

## Evidence
Privacy setting; it does not change frame rate or latency.

## Trade-offs & risks
Settings pages no longer show online help links and tips.

## When not to use it
If you use the help links in Settings.

## Sources
1. https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-settings
