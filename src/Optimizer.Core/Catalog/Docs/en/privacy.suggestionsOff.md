# Tips, suggestions and welcome screens off

## Summary
Turns off tips, suggested content in Settings and Start, and the welcome experience after updates.

## How it works
These are the user switches behind Settings > Privacy & security > General, Settings > System > Notifications > Additional settings and the Start recommendations [1].

## Why it can help
Less data leaves this PC. No measurable effect on performance.

## Evidence
Privacy setting; it does not change frame rate or latency.

## Trade-offs & risks
You no longer see tips for new Windows features.

## When not to use it
If the tips help you discover new features.
