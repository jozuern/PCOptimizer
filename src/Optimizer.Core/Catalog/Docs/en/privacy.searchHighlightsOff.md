# Search highlights off

## Summary
Removes the daily highlights and trending content from the search box and search home.

## How it works
The policy "Allow search highlights" is set to off [1].

## Why it can help
Less data leaves this PC. No measurable effect on performance.

## Evidence
Privacy setting; it does not change frame rate or latency.

## Trade-offs & risks
The search home no longer shows daily content.

## When not to use it
If you like the daily highlights.

## Sources
1. https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-search
