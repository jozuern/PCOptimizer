# Leftovers from other tweak tools

## Summary
::: status Problem
Values from older tweak guides or tools were found that no longer work on Windows 11 24H2 or newer, or that slow the PC down.
:::
::: status Ok,Unknown,Info,Unsupported
Checks for values left by other tweak tools that are ineffective or harmful on Windows 11 24H2 and newer.
:::

## Why it matters
Tweak tools and guides often set values that made sense on older Windows versions. Some stop working after an update and some cause problems: OverlayTestMode = 5 no longer disables MPO on 24H2 and is linked to black flashes [1], and the boot option useplatformclock forces the slow HPET timer [2].

## How we detected it
We check the known leftover values from the catalog: registry values directly, boot options through bcdedit (needs administrator rights; without them the boot part shows as unknown).

## How to fix
Each leftover has a fix in Tweaks > Leftovers. The boot option is an Expert change, because it touches the boot configuration.

## How to check the fix
Run the scan again. The list should be empty.
