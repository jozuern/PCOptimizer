# Ryzen X3D with two chiplets: power plan

## Summary
::: status Problem
Your Ryzen X3D has 3D V-Cache on only one of its two chiplets. The active plan is not Balanced, so Windows may run games on the chiplet without the extra cache.
:::
::: status Ok,Unknown,Info,Unsupported
Your Ryzen X3D has 3D V-Cache on one of two chiplets. Balanced is active, which the AMD driver needs to keep games on the V-Cache chiplet.
:::

## Why it matters
On these processors only one chiplet (CCD) has the large stacked L3 cache that makes X3D chips fast in games. The AMD chipset driver ("3D V-Cache Performance Optimizer") and the Xbox Game Bar detect a running game and park the cores of the other chiplet, so the game runs on the cache chiplet. That mechanism depends on core parking in the **Balanced** plan. High performance, Ultimate Performance or tools that disable core parking switch it off, and games can then spread across both chiplets with lower and less stable frame rates.

## How we detected it
We read the processor's cache layout from Windows: two L3 cache domains of clearly different size (the larger at least twice the smaller) mean one chiplet with V-Cache. The model list in the catalog confirms known models. Then we read the active power plan's type.

## How to fix
1. Select the **Balanced** power plan (Settings > System > Power).
2. Install the current AMD chipset driver from amd.com (it contains the V-Cache optimizer).
3. Keep the Xbox Game Bar installed and updated; do not remove it with debloat tools.
4. In the BIOS, leave **CPPC Dynamic Preferred Cores** on **Auto** or **Driver**.

## How to check the fix
Run the scan again. During a game, Task Manager should show load mainly on the first half of the cores.
