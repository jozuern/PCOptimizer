# Ryzen X3D with two chiplets: power plan

## Summary
::: status Problem
Your Ryzen X3D has 3D V-Cache on one of two chiplets. The plan is not Balanced or has core parking off, so games may run on the chiplet without the extra cache.
:::
::: status Ok
Your Ryzen X3D has 3D V-Cache on one of two chiplets. The Balanced plan is active, which keeps core parking available for AMD's driver.
:::
::: status Unknown,Info,Unsupported
Your Ryzen X3D has 3D V-Cache on one of two chiplets. We could not read the active power plan.
:::

## Why it matters
On these processors only one chiplet (CCD) has the large stacked L3 cache that makes X3D chips fast in games. The AMD chipset driver installs the "3D V-Cache Performance Optimizer"; it uses the Xbox Game Bar's game detection as the cue to park the cores of the other chiplet, so the game runs on the cache chiplet [1]. That mechanism depends on core parking. Windows switches core parking off entirely when the minimum share of unparked cores is set to 100 % [2], which some tweak tools and custom plans do. Notebookcheck tested with the Balanced plan following AMD's recommendation [1]; we found no AMD document that states this requirement directly. Without parking, games can spread across both chiplets, and the effect on frame rate depends on the game.
::: variant parkingOff
Here the Balanced plan is active, but its minimum share of unparked cores is set to 100 %, so core parking is off.
:::

## How we detected it
We read the processor's cache layout from Windows: two L3 cache domains of clearly different size (the larger at least twice the smaller) mean one chiplet with V-Cache. The model list in the catalog confirms known models. Then we read the active power plan's type and whether its minimum share of unparked cores is 100 %.

## How to fix
1. Select the **Balanced** power plan in **Control Panel > Hardware and Sound > Power Options**.
2. Install the current AMD chipset driver from amd.com (it contains the V-Cache optimizer [1]).
3. Keep the Xbox Game Bar installed and updated; do not remove it with debloat tools.
4. If a tweak tool turned core parking off, undo that change in the tool, or reset the Balanced plan to its defaults (Control Panel > Power Options > Change plan settings > Restore default settings for this plan).

## How to check the fix
Run the scan again. During a game, Task Manager should show load mainly on the cores of one chiplet.
