# Advertising ID off

## Summary
Turns off the advertising ID that apps can use to show personalized ads across apps.

## How it works
The policy "Turn off the advertising ID" makes Windows return no advertising ID to apps [1][2].

## Why it can help
Less data leaves this PC. No measurable effect on performance.

## Evidence
Privacy setting; it does not change frame rate or latency.

## Trade-offs & risks
Ads in apps are no longer personalized; their number stays the same.

## When not to use it
Keep it if you want personalized ads in apps.
