# Graphics card without a driver

## Summary
::: status Problem
Windows runs a graphics adapter with the Microsoft Basic Display Adapter. Without the vendor driver, 3D acceleration and games do not work properly.
:::
::: status Info
An extra graphics adapter without a display (usually the processor's graphics) runs on the Microsoft Basic Display Adapter. Your graphics card has its vendor driver.
:::
::: status Ok,Unknown,Unsupported
Checks that every graphics adapter uses its vendor driver, not the Microsoft Basic Display Adapter.
:::

## Why it matters
The Microsoft Basic Display Adapter is the driver Windows uses when no vendor driver is present or working. It renders 3D through the processor (WARP) instead of the graphics card, and on UEFI PCs it cannot change resolution or refresh rate [1]. Games run at a fraction of the normal speed or refuse to start. It usually appears after a failed driver update, during a driver installation or on a fresh Windows install [1].
::: variant secondary
Here the adapter on the basic driver drives no display, and your graphics card has its vendor driver, so games are not affected. Installing the processor graphics driver (or the board's chipset and graphics package) clears this entry.
:::

## How we detected it
We read every graphics adapter from Windows (WMI) and check its driver: an adapter counts as basic when it uses `display.inf` or is named "Microsoft Basic Display Adapter". An adapter on the basic driver that drives no display, next to a graphics card with its vendor driver, is shown as information only. Right after a driver update Windows can use the basic driver for a short time; run the scan again after a restart.

## How to fix
1. Download the current driver from the vendor: NVIDIA (nvidia.com/drivers), AMD (amd.com/support) or Intel (intel.com/download-center).
2. Run the installer and restart.
3. If the installation fails, check Device Manager for a yellow warning sign on the adapter and note the error code.

## How to check the fix
Run the scan again. The adapter should show the vendor (NVIDIA, AMD or Intel) as driver provider.
