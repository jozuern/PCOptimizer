# Graphics card without a driver

## Summary
::: status Problem
Windows runs a graphics adapter with the Microsoft Basic Display Adapter. Without the vendor driver, 3D acceleration and games do not work properly.
:::
::: status Ok,Unknown,Info,Unsupported
Checks that every graphics adapter uses its vendor driver, not the Microsoft Basic Display Adapter.
:::

## Why it matters
The Microsoft Basic Display Adapter is a fallback driver. It draws the desktop through the processor and supports neither DirectX 12 games nor the graphics card's own features. Games either do not start or run at a fraction of the normal speed. It usually appears after a failed driver update, after Windows Update replaced a driver, or on a fresh Windows install.

## How we detected it
We read every graphics adapter from Windows (WMI) and check its driver package: the basic driver uses `display.inf` and the name "Microsoft Basic Display Adapter".

## How to fix
1. Download the current driver from the graphics card vendor: NVIDIA (nvidia.com/drivers), AMD (amd.com/support) or Intel (intel.com/download-center).
2. Run the installer and restart.
3. If the installation fails, check Device Manager for a yellow warning sign on the adapter and note the error code.

## How to check the fix
Run the scan again. The adapter should show the vendor (NVIDIA, AMD or Intel) as driver provider.
