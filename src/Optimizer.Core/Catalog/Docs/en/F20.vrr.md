# Variable refresh rate (G-SYNC, FreeSync)

## Summary
::: variant off
{{display}} supports variable refresh, but G-SYNC is off. Turning it on removes tearing and stutter without the delay of V-Sync.
:::
::: variant on
G-SYNC is on for {{display}}.
:::
::: variant notPossible
{{display}} looks like a variable refresh monitor, but the driver reports it as not possible. Usually the connection or a monitor setting.
:::
::: variant fixed
{{display}} does not support variable refresh.
:::
::: variant nvidiaUnknown,otherVendor
{{display}} looks like a variable refresh monitor. We cannot read the setting for this graphics card, so check it in the driver.
:::

## Why it matters
With a fixed refresh rate, frames that are not ready in time either tear (V-Sync off) or wait for the next refresh (V-Sync on), which causes stutter and delay. With variable refresh rate (VRR), the monitor waits for the graphics card instead, within its range. Frame rate drops then look much smoother, without the delay of V-Sync.

## How we detected it
::: variant off,on,notPossible,fixed
We read the VRR state of the display through NVIDIA's driver interface (NVAPI): whether VRR is possible on this display and connection, and whether G-SYNC is turned on.
:::
::: variant nvidiaUnknown,otherVendor
The driver of this graphics card has no interface we can read, so we use the monitor's EDID: a wide refresh range (for example 48 Hz to 144 Hz) with continuous frequency support is typical for VRR monitors. That is a hint, not proof.
:::

## How to fix
::: variant off
1. Open **NVIDIA Control Panel > Display > Set up G-SYNC**.
2. Tick **Enable G-SYNC, G-SYNC Compatible**, choose full screen or full screen and windowed mode, select {{display}} and tick **Enable settings for the selected display model**.
3. Recommended with G-SYNC: in Manage 3D settings set **Vertical sync = On** and set a frame limit a few FPS below the refresh rate [1].
:::
::: variant notPossible
1. Turn on **FreeSync** or **Adaptive-Sync** in the monitor's own menu.
::: if hdmi
2. Use **DisplayPort**. G-SYNC Compatible over HDMI needs an HDMI 2.1 VRR capable card and monitor (GeForce RTX 30 series and newer).
:::
3. Update the graphics driver and run the scan again.
4. If the monitor is not on NVIDIA's list of validated displays, G-SYNC Compatible can still work but must be enabled manually [2].
:::
::: variant otherVendor
::: if amd
1. Open **AMD Software: Adrenalin Edition > Gaming > Display** and turn on **AMD FreeSync** for this display.
:::
::: if intel
1. Open **Intel Graphics Software > Display** and turn on **Adaptive Sync** (on Arc cards and supported integrated graphics).
:::
2. Turn on FreeSync or Adaptive-Sync in the monitor's own menu as well.
:::
::: variant nvidiaUnknown
1. Open **NVIDIA Control Panel > Display > Set up G-SYNC** and check whether G-SYNC is offered for this display.
:::
::: variant on,fixed
No action needed.
:::

## How to check the fix
Run the scan again. With the G-SYNC indicator (NVIDIA Control Panel > Display > G-SYNC Compatible Indicator) you can see it working in a game.
