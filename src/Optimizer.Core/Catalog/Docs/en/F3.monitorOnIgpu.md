# Monitor connected to the motherboard instead of the graphics card

## Summary
::: status Problem
{{displays}} is plugged into the motherboard, so the processor's integrated graphics drives it instead of the {{dgpu}}.
:::
::: status Ok,Unknown,Info,Unsupported
Checks that every monitor on a desktop PC is plugged into the graphics card, not into the motherboard.
:::

## Why it matters
The video outputs on the motherboard belong to the integrated graphics in the processor. A monitor plugged in there is driven by that much slower GPU. Windows can still render games on the graphics card and copy each frame across, but that costs performance, adds latency and often limits refresh rate and features like G-SYNC or FreeSync. On desktops with a graphics card, the monitor cable belongs in the card's outputs.

## How we detected it
For every active display we read which graphics adapter drives it (Windows display configuration API) and compare that adapter with the list of GPUs. An adapter counts as integrated when its name matches the integrated GPU patterns in the catalog (for example Intel UHD Graphics or AMD Radeon Graphics without an RX model number).

## How to fix
1. Shut down the PC.
2. Move the monitor cable from the motherboard's outputs (the I/O panel next to the USB ports) to an output on the graphics card (usually lower, in a horizontal row).
3. Start the PC. If the screen stays black, connect the cable to the graphics card first and then check that the BIOS setting for the primary display is set to the PCIe graphics card.

## How to check the fix
Run the scan again. Every display should show your graphics card under "Connected to".
