# Monitor connected to the motherboard instead of the graphics card

## Summary
::: status Problem
{{displays}} is plugged into the motherboard, so the processor's integrated graphics drives it instead of the {{dgpu}}.
:::
::: status Info
{{displays}} is plugged into the motherboard. Your main monitor is on the {{dgpu}}, so this only matters if you play on that monitor.
:::
::: status Ok
Every monitor is plugged into the graphics card.
:::
::: status Unknown,Unsupported
Checks that the main monitor of a desktop PC is plugged into the graphics card, not into the motherboard.
:::

## Why it matters
The video outputs on the motherboard belong to the integrated graphics in the processor. A monitor plugged in there is driven by that GPU. Windows can still render games on the graphics card, but then each finished frame has to be passed to the integrated graphics for display, the same way NVIDIA describes for laptops with Optimus [1]. That costs performance and adds delay, and the refresh rates and variable refresh (G-SYNC, FreeSync) you can use then depend on the motherboard output and the integrated graphics. On desktops with a graphics card, the cable of the monitor you play on belongs in the card's outputs.
::: variant secondary
A second monitor on the motherboard can be a deliberate choice, for example for chat or a stream preview. It does not affect games on the main monitor.
:::

## How we detected it
For every active display we read which graphics adapter drives it (Windows display configuration API) and compare that adapter with the list of GPUs. An adapter counts as integrated when its name matches the integrated GPU patterns in the catalog (for example Intel UHD Graphics or AMD Radeon Graphics without an RX model number). Only the main display (the one at the desktop origin) counts as a problem; other displays on the integrated graphics are information. If we cannot match a display to an adapter, the result is unknown. Built-in screens of all-in-one PCs are not judged, because their wiring is fixed.

## How to fix
::: status Problem,Info
1. Shut down the PC.
2. Move the monitor cable from the motherboard's outputs (the I/O panel next to the USB ports) to an output on the graphics card (usually lower, in a horizontal row).
3. Start the PC. If the screen stays black, connect the cable to the graphics card first and then check in the BIOS that the primary display is set to the PCIe graphics card. If your system drive uses BitLocker, suspend it before you change BIOS settings, or Windows may ask for the recovery key at the next start [2].
:::
::: status Ok,Unknown,Unsupported
No action needed.
:::

## How to check the fix
Run the scan again. Every display you play on should show your graphics card under "Connected to".
