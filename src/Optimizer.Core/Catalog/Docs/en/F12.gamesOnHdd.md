# Game library on a hard disk

::: status Problem
::: variant smr

:::
::: variant default
The game library {{library}} is on a hard disk ({{disk}}). Games load slowly and can stutter when they stream data during play.
:::

::: status Ok
The game library {{library}} is on an SSD.
:::
::: status Unknown,Info,Unsupported
Checks whether your game libraries are on a hard disk or an SSD.
:::

## Why it matters
Many current games load textures and level data while you play. A hard disk has to wait for the platter to turn before each random access, on average about 4 ms at 7200 rpm before the head even moves [1]; an SSD has no moving parts. Games on a hard disk therefore show long loading screens, pop-in and stutter during streaming. Some recent games list an SSD as a requirement, for example Starfield [2]. Drives with shingled magnetic recording (SMR) are slower again when writing a lot of data, for example during game installs and updates [3][4].
::: variant smr
This drive model is on the catalog's list of SMR drives, which is built from the lists Western Digital, Seagate and Toshiba publish [3][4][5].
:::

## How we detected it
We read the library folders from Steam (`libraryfolders.vdf`), and the Xbox app's `.GamingRoot` marker on drive roots. We then map each library's drive letter to its physical disk and read the media type (HDD or SSD) from Windows storage management. Some USB and RAID setups report no media type; the result is then unknown. SMR drives are recognized by model number from the catalog; a drive missing from the list can still be SMR.

## How to fix
::: status Problem
1. Move games you play often to an SSD. In Steam: **Settings > Storage**, select the game, then **Move**. The Xbox app has **Manage > Files > Move**.
2. Keep the hard disk for games you rarely play, or for videos and backups.
3. If the board has a free M.2 slot, an NVMe SSD is the simplest upgrade.
:::
::: status Ok,Unknown,Info,Unsupported
No action needed.
:::

## How to check the fix
Run the scan again. The library should show an SSD as disk.
