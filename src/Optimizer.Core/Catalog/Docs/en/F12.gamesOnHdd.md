# Game library on a hard disk

## Summary
::: variant smr
The game library {{library}} is on {{disk}}, a hard disk with shingled recording (SMR). Load times are long and texture streaming can stutter.
:::
::: variant default
The game library {{library}} is on a hard disk ({{disk}}). Games load slowly and can stutter when they stream data during play.
:::

## Why it matters
Many current games load textures and level data while you play. A hard disk needs several milliseconds per random access, an SSD a fraction of a millisecond, so games on a hard disk show long loading screens, pop-in and stutter during streaming. Some recent games list an SSD as a requirement. Drives with shingled magnetic recording (SMR) are slower again when writing a lot of data, for example during game installs and updates.
::: variant smr
This drive model is on the catalog's list of SMR drives.
:::

## How we detected it
We read the library folders from Steam (`libraryfolders.vdf`), and the Xbox app's `.GamingRoot` marker on drive roots. We then map each library's drive letter to its physical disk and read the media type (HDD or SSD) from Windows storage management. SMR drives are recognized by model number from the catalog.

## How to fix
1. Move games you play often to an SSD. In Steam: **Settings > Storage**, select the game, then **Move**. The Xbox app has **Manage > Files > Move**.
2. Keep the hard disk for games you rarely play, or for videos and backups.
3. A 1 TB NVMe SSD is usually the best value upgrade if the board has a free M.2 slot.

## How to check the fix
Run the scan again. The library should show an SSD as disk.
