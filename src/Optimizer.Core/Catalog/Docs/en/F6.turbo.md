# Processor turbo disabled by the power plan

## Summary
::: status Problem
The active power plan keeps the processor below its turbo clock (maximum state under 100 % or boost mode off). CPU-limited games lose speed.
:::
::: status Ok,Unknown,Info,Unsupported
Checks that the power plan lets the processor reach its turbo clock when plugged in.
:::

## Why it matters
Two power plan settings control turbo. "Maximum processor state" sets the highest performance Windows requests from the processor, as a percentage of its maximum performance [2]; below 100 % Windows requests less than the maximum, which cuts into the turbo range above the base clock. "Processor performance boost mode" set to Disabled turns off boosting above the nominal performance [1]. Processors run well above their base clock in games when they may boost, so a disabled turbo costs frame rate in games that are limited by the processor. How much depends on the processor and the game; we have no measured figure for it. These values are sometimes set by "silent" or battery tips, or by other tweak tools.

If you turned boost off on purpose, for example with this app's **Quiet and cool** profile, you can ignore this.

## How we detected it
We read the active plan's plugged-in values for `PROCTHROTTLEMAX` (maximum processor state) and `PERFBOOSTMODE` (boost mode) through the Windows power API, by their GUIDs, so the check works in any Windows language. On processors with two core types Windows has a second maximum state setting for the second core class (`PROCTHROTTLEMAX1`) [2]; we do not read it.

## How to fix
1. Open **Control Panel > Power Options > Change plan settings > Change advanced power settings**.
2. Under **Processor power management**, set **Maximum processor state** (Plugged in) to 100 %.
3. If **Processor performance boost mode** is listed, set it to **Enabled** or **Aggressive**. The setting is hidden by default; if it is not shown, the value is usually fine.

Or use **Fix** at the top of this panel: the app makes the change for you and can undo it later.

## How to check the fix
Run the scan again, or watch the CPU speed in Task Manager > Performance while a game runs: it should rise above the base clock.
