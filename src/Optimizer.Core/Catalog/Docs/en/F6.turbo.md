# Processor turbo disabled by the power plan

## Summary
::: status Problem
The active power plan keeps the processor below its turbo clock (maximum state under 100 % or boost mode off). Games lose a large part of the CPU's speed.
:::
::: status Ok,Unknown,Info,Unsupported
Checks that the power plan lets the processor reach its turbo clock when plugged in.
:::

## Why it matters
Two power plan settings control turbo. "Maximum processor state" below 100 % (even 99 %) tells Windows not to request turbo frequencies, so the CPU stays at or below its base clock. "Processor performance boost mode" set to Disabled has the same effect. Modern CPUs run much higher than their base clock in games (an i7-9700K: 3.6 GHz base, up to 4.9 GHz turbo), so a disabled turbo can cost 20 % or more in CPU-limited games. These values are sometimes set by "silent" or battery tips, or by other tweak tools.

## How we detected it
We read the active plan's plugged-in values for `PROCTHROTTLEMAX` (maximum processor state) and `PERFBOOSTMODE` (boost mode) through the Windows power API, by their GUIDs, so the check works in any Windows language.

## How to fix
1. Open **Control Panel > Power Options > Change plan settings > Change advanced power settings**.
2. Under **Processor power management**, set **Maximum processor state** (Plugged in) to 100 %.
3. If **Processor performance boost mode** is listed, set it to **Enabled** or **Aggressive**. The setting is hidden by default; if it is not shown, the value is usually fine.

Or use **Fix** at the top of this panel: the app makes the change for you and can undo it later.

## How to check the fix
Run the scan again, or watch the CPU speed in Task Manager > Performance while a game runs: it should rise above the base clock.
