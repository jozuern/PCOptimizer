# Gaming laptop running on battery

## Summary
::: status Problem
The laptop runs on battery. On battery, the graphics card and processor get much less power, so games run far slower than with the power adapter.
:::
::: status Ok,Unknown,Info,Unsupported
Checks whether the laptop is connected to its power adapter.
:::

## Why it matters
Gaming laptops need their power adapter for full performance. On battery, Windows, the graphics driver and the laptop firmware limit how much power the graphics card and processor may draw, and many laptops lock their performance mode. Frame rates can drop to a fraction of what the same laptop reaches plugged in.

## How we detected it
We read the Windows power status (`SYSTEM_POWER_STATUS.ACLineStatus`), which reports whether the PC runs on mains power [1]. Windows can also report the status as unknown; the result is then unknown, not "on battery".

## How to fix
1. Connect the laptop's own power adapter. A USB-C charger with lower wattage may not supply enough power for gaming.
2. In the laptop manufacturer's app, check that the performance mode for the power adapter is not set to a silent or battery mode.

## How to check the fix
Run the scan again with the adapter connected. "Plugged in" should show Yes.
