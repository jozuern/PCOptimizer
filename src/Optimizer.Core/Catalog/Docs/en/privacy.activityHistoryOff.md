# Activity history off

## Summary
Stops Windows from collecting and uploading your activity history (opened apps, files and websites).

## How it works
Three policies under System turn off the activity feed and the publishing and upload of user activities [1].

## Why it can help
Less background logging. No measurable performance effect.

## Evidence
Privacy setting; no frame-rate effect.

## Trade-offs & risks
Features that use activity history (resuming work across devices) stop working.

## When not to use it
Keep it if you use cross-device activity features.
