# Low amount of memory (8 GB or less)

## Summary
::: status Problem
The PC has 8 GB of memory or less. Many current games plus Windows, browser and chat need more, which causes stutter from swapping to disk.
:::
::: status Ok,Unknown,Info,Unsupported
Checks that the PC has more than 8 GB of memory.
:::

## Why it matters
When games, Windows and background apps need more memory than is installed, Windows moves data to the page file on the disk and loads it back when needed. Even on a fast SSD that takes far longer than a memory access, and it shows up as stutter and poor 1 % lows rather than a lower average frame rate. Many games released since 2023 list 16 GB as their recommended amount. No software setting replaces missing memory.

## How we detected it
We read the installed memory from Windows (WMI) and treat 8 GB or less as low.

## How to fix
1. Upgrade to 16 GB, or 32 GB for current games plus streaming or many background apps.
2. Buy two identical modules (a kit), so the memory runs in dual channel (see the dual-channel check).
3. Check the board's manual or the laptop's specifications for the supported type (DDR4 or DDR5), speed and whether the memory is soldered.
4. Until then, close the browser and other large apps while gaming.

## How to check the fix
Run the scan again after the upgrade. The installed memory should show the new amount.
