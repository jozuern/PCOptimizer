# App launch tracking off

## Summary
Stops Windows from tracking which apps you start to improve Start and search results.

## How it works
This is the switch "Let Windows improve Start and search results by tracking app launches" in Settings > Privacy & security > General [1].

## Why it can help
Less data leaves this PC. No measurable effect on performance.

## Evidence
Privacy setting; it does not change frame rate or latency.

## Trade-offs & risks
The "Most used" list in Start no longer updates.

## When not to use it
If you use the most used apps list.
