# Wi-Fi connected on 2.4 GHz

## Summary

## Why it matters
The 2.4 GHz band has few channels and is shared with neighbors' networks, Bluetooth and other devices, so interference is more likely. In games that shows as ping spikes and packet loss. 5 GHz and 6 GHz have more channels and usually less interference, at the cost of range through walls. A cable is still the most stable connection.

## How we detected it
We read the frequency of the access point the PC is connected to through the Windows Wi-Fi API [1], and which bands the same network name is visible on. The check is skipped while a physical network cable connection is active; virtual adapters (Hyper-V, WSL, VPN) do not count.

Windows only gives these access point details to apps that may use your precise location (Settings > Privacy & security > Location). Without that permission the Wi-Fi API answers "access denied", and Windows can show a one-time prompt asking for location access [2]. The app does not use or store your location; it only reads the band of the current connection.
::: variant noLocation
If you want this check, allow location access for desktop apps in Settings > Privacy & security > Location (or press Win+R and enter `ms-settings:privacy-location`) [2], then run the scan again. You can also skip it: the rest of the scan does not need location access.
:::

## How to fix
::: status Problem
1. In Device Manager > Network adapters > your Wi-Fi adapter > Advanced, set **Preferred Band** (name differs by vendor) to **5 GHz** or **6 GHz**.
2. Or give the 5 GHz network its own name in the router and connect to that one.
3. If the signal on 5 GHz is weak, move the router or the PC closer, or use a cable.
:::
::: status Info
1. Check that the router has 5 GHz turned on. Older routers and some adapters only support 2.4 GHz.
2. For gaming, a network cable is the most stable option.
:::
::: status Ok,Unknown,Unsupported
No action needed.
:::

## How to check the fix
Run the scan again. The Wi-Fi band should show 5 GHz or 6 GHz.
