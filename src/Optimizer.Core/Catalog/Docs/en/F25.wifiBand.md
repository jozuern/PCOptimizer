# Wi-Fi connected on 2.4 GHz

## Summary
::: status Problem
Connected to {{ssid}} on 2.4 GHz, although the network is also available on 5 or 6 GHz here. The faster band has less interference.
:::
::: status Info
Connected to {{ssid}} on 2.4 GHz. The network is not visible on 5 or 6 GHz from here.
:::
::: status Ok,Unknown,Unsupported
Checks which Wi-Fi band the connection uses.
:::

## Why it matters
The 2.4 GHz band has only three channels that do not overlap and is shared with neighbors' networks, Bluetooth and microwave ovens. In games that shows as ping spikes and packet loss. 5 GHz and 6 GHz have more channels and less interference, at the cost of range through walls. A cable is still the most stable connection.

## How we detected it
We read the frequency of the access point the PC is connected to through the Windows Wi-Fi API, and which bands the same network name is visible on. The check is skipped while a cable connection is active.

## How to fix
::: status Problem
1. In Device Manager > Network adapters > your Wi-Fi adapter > Advanced, set **Preferred Band** (name differs by vendor) to **5 GHz** or **6 GHz**.
2. Or give the 5 GHz network its own name in the router and connect to that one.
3. If the signal on 5 GHz is weak, move the router or the PC closer, or use a cable.
:::
::: status Info
1. Check that the router has 5 GHz turned on. Older routers and some adapters only support 2.4 GHz.
2. For gaming, a network cable is the most stable option.
:::
::: status Ok,Unknown,Unsupported
No action needed.
:::

## How to check the fix
Run the scan again. The Wi-Fi band should show 5 GHz or 6 GHz.
