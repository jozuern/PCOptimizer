# Overlay and capture programs running

## Summary
::: status Info
Overlay or capture programs are running: {{overlays}}. Each hooks into the game's frame output. Turn off the ones you do not use.
:::
::: status Ok,Unknown,Problem,Unsupported
Lists running programs that draw over games or capture them.
:::

## Why it matters
Overlays (Discord, NVIDIA App, Steam, Xbox Game Bar) and capture tools (OBS, Medal) insert their code into the game's presentation path to draw on the image or to record it. One overlay usually costs little. Several at once, or an old version, can cause frame time spikes or crashes with some games and anti-cheats. This is information, not a problem: if you use them, keep them.

## How we detected it
We compare the running processes with a list of known overlay and capture programs. A running process does not prove that its overlay is on, so check the program's settings.

## How to fix
Menu names change between versions of these programs, and we found no vendor page that lists all of them. If a path below does not match, look for "overlay" in the program's settings.

1. **Discord:** User Settings > Game Overlay > Enable in-game overlay.
2. **NVIDIA App:** Settings > Features > NVIDIA Overlay.
3. **Xbox Game Bar:** Settings > Gaming > Game Bar.
4. **Steam:** Settings > In Game > Enable the Steam Overlay while in-game.
5. Close capture and monitoring programs you do not need while playing, or stop them from starting with Windows on the **Startup** page or in Settings > Apps > Startup [1].

## How to check the fix
Run the scan again while the programs you need are running.
