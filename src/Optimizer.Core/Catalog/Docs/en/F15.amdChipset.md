# AMD Chipset Software not installed

## Summary
::: status Problem
AMD Chipset Software is missing. On {{cpu}} it installs the 3D V-Cache driver that moves games to the cache die. Install it.
:::
::: status Info
AMD Chipset Software is not installed. Windows Update provides basic drivers, but AMD's package is the current and complete set.
:::
::: status Ok
AMD Chipset Software is installed.
:::
::: status Unknown,Unsupported
Checks whether AMD's chipset driver package is installed.
:::

## Why it matters
AMD's chipset package contains the drivers for the board's chipset functions and the processor power management settings for Ryzen [1].
::: variant x3d
On processors with 3D V-Cache on only one of two dies, the package also installs the AMD 3D V-Cache Performance Optimizer driver. Together with Game Mode and the Balanced plan, it parks the cores without the extra cache while a game runs, so the game runs on the cache die. Without it, games can land on the wrong die and lose frame rate.
:::

## How we detected it
We look for "AMD Chipset Software" (or the older package names) in the list of installed programs. Drivers that came through Windows Update do not appear there, so "not installed" only means AMD's package is missing.

## How to fix
1. Download **AMD Chipset Software** for your chipset from AMD's driver page [1] (or from your mainboard's support page).
2. Install it and restart.
::: variant x3d
3. Keep the **Balanced** power plan and Game Mode on, so the V-Cache driver can park the cores.
:::

## How to check the fix
Run the scan again. The package should be listed with its version.
