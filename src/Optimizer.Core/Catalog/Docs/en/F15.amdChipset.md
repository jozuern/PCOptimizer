# AMD Chipset Software not installed

## Summary
::: status Problem
AMD Chipset Software is missing. On {{cpu}} it installs the 3D V-Cache driver that moves games to the cache die. Install it.
:::
::: status Info
AMD Chipset Software is not installed. Windows Update provides basic drivers, but AMD's package is the current and complete set.
:::
::: status Ok
AMD Chipset Software is installed.
:::
::: status Unknown,Unsupported
Checks whether AMD's chipset driver package is installed.
:::

## Why it matters
AMD's chipset package contains the drivers for the board's chipset functions and the processor power management settings for Ryzen.
::: variant x3d
On processors with 3D V-Cache on only one of two dies, the package also installs the AMD 3D V-Cache Performance Optimizer driver [2]. It uses the Xbox Game Bar's game detection to park the cores without the extra cache while a game runs, so the game runs on the cache die [2]. Without it, games can land on the other die, and the effect on frame rate depends on the game.
:::

## How we detected it
We look for "AMD Chipset Software" (or the older package names) in the list of installed programs. Drivers that came through Windows Update or a PC maker's package do not appear there, so "not installed" only means AMD's package is missing; the V-Cache driver can still be present from another source.

## How to fix
1. Download **AMD Chipset Software** for your chipset from AMD's driver page [1] (or from your mainboard's support page).
2. Install it and restart.
::: variant x3d
3. Keep the **Balanced** power plan and the Xbox Game Bar installed and updated, so the V-Cache driver can park the cores (see the check "Ryzen X3D with two chiplets: power plan").
:::

## How to check the fix
Run the scan again. The package should be listed with its version.
