# Web results in Start search off

## Summary
Start menu search shows only results from this PC, no Bing web results or suggestions.

## How it works
A user policy turns off search box suggestions, which removes the web results from the Start menu and taskbar search [1].

## Why it can help
Less data leaves this PC. No measurable effect on performance.

## Evidence
Privacy setting; it does not change frame rate or latency.

## Trade-offs & risks
You search the web in the browser instead of the Start menu.

## When not to use it
If you use the Start menu to search the web.
