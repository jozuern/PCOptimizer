# Inking and typing personalization off

## Summary
Stops Windows from collecting your typing and handwriting to build a personal dictionary, and turns off typing insights.

## How it works
Policies stop the automatic learning from typed text and handwriting; the user settings stop collecting contacts for suggestions and turn off typing insights [1][2].

## Why it can help
Less data leaves this PC. No measurable effect on performance.

## Evidence
Privacy setting; it does not change frame rate or latency.

## Trade-offs & risks
Text suggestions and handwriting recognition learn less from you.

## When not to use it
If you rely on handwriting with a pen.
