# Games may run on the integrated graphics

## Summary
::: status Problem
Games without a "High performance" GPU preference: {{count}}. On this PC with two GPUs they may run on the integrated graphics instead of the {{dgpu}}.
:::
::: status Ok,Unknown,Info,Unsupported
Checks that games use the dedicated graphics card on PCs that also have integrated graphics.
:::

## Why it matters
On laptops with hybrid graphics, and on desktops with the processor's graphics enabled, Windows decides per app which GPU renders it. Without a preference, some games start on the power-saving integrated GPU and run at a fraction of the frame rate.

## How we detected it
We read the installed Steam games (appmanifest files), guess each game's main executable, and read your per-app GPU preferences (UserGpuPreferences). A game without GpuPreference=2 counts as missing. The executable guess can be wrong for games that start through a launcher.

## How to fix
Use the one-click fix to set "High performance" for the listed games, or set it per game in Settings > System > Display > Graphics.

## How to check the fix
Run the scan again. In a running game, Task Manager > Performance > GPU shows which GPU does the work.
