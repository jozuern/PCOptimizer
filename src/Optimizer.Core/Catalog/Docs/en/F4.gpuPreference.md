# Games may run on the integrated graphics

## Summary
::: status Problem,Info
Games without a Windows "High performance" GPU preference: {{count}}. The graphics driver may already send them to the {{dgpu}}; setting the preference makes sure.
:::
::: status Ok

::: status Unknown,Unsupported
Checks whether games have a Windows GPU preference on PCs that have integrated graphics and a graphics card.
:::

## Why it matters
On laptops with hybrid graphics, and on desktops with the processor's graphics enabled, more than one GPU can render a game. A game that asks DirectX for its adapter without a preference gets the adapter that drives the main display first [2], and on a laptop that is usually the integrated GPU. The graphics driver can still route the game to the graphics card: NVIDIA's driver profiles tell the system which games need the GeForce GPU [1]. A game that does end up on the integrated GPU runs at a much lower frame rate. The Windows preference "High performance" asks for the highest performing GPU for that app [3].

## How we detected it
We read the installed Steam games (appmanifest files), guess each game's main executable, and read your per-app GPU preferences in Windows (the list behind Settings > System > Display > Graphics). A game without the "High performance" preference counts as missing. We cannot see whether the NVIDIA or AMD driver already routes a game to the graphics card through its own profile, and we do not measure which GPU a running game uses. So this is a precaution, not proof that a game runs on the wrong GPU. The executable guess can also be wrong for games that start through a launcher.

## How to fix
::: status Problem,Info
Use the one-click fix to set "High performance" for the listed games, or set it per game in **Settings > System > Display > Graphics**.
:::
::: status Ok,Unknown,Unsupported
No action needed.
:::

## How to check the fix
Run the scan again. In a running game, Task Manager > Performance > GPU shows which GPU does the work.
