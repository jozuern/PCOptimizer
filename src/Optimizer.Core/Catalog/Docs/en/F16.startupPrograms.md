# Many programs start with Windows

## Summary
::: status Info
{{count}} programs from other vendors start with Windows. Each costs boot time and memory, and some keep working in the background while you play.
:::
::: status Ok,Unknown,Problem,Unsupported
Counts the programs from other vendors that start when you sign in.
:::

## Why it matters
Launchers, chat programs, RGB and peripheral tools, updaters and cloud sync clients often start with Windows. Each one makes signing in slower and takes memory. Some check for updates or sync files at intervals, which can show as short stutters in games. Programs you use every day can stay; the rest can start when you open them.

## How we detected it
We read the Run keys, the Startup folders and the scheduled tasks that start at sign-in or boot, and count the enabled entries that are not part of Windows (by signature). We report from more than 8 entries on.

## How to fix
1. Open the **Startup** page in this app. Every entry shows its publisher and where it starts from.
2. Turn off the programs you do not need right after signing in. The program itself stays installed and you can still start it yourself.
3. Keep drivers' helper programs for things you use (audio control panels, touchpad software on laptops).

## How to check the fix
Run the scan again; the count drops. Signing in should be faster.
