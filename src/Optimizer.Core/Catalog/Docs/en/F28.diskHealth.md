# Drive health

## Summary
::: status Problem
Windows reports a problem with {{disk}}: errors, wear or a failing health check. Back up your data now.
:::
::: status Ok
{{disk}} reports no health problems.
:::
::: status Unknown,Info,Unsupported
Shows the health Windows reads from the drive (S.M.A.R.T. or NVMe health log).
:::

## Why it matters
Drives report their own condition: errors they could not correct, how much of an SSD's rated write endurance is used, and temperatures. A drive that reports such problems can fail without further warning, and data on it can be lost. Before it fails, it often slows down, which shows as long loading times and stutter.

## How we detected it
We read Windows Storage Management: the health status of each drive and its reliability counters (temperature, wear, uncorrected read and write errors, power-on hours) [1]. The counters need administrator rights. A problem is: health "Warning" or "Unhealthy", 90 % or more wear, or any uncorrected error.

## How to fix
::: status Problem
1. Back up important files to another drive or the cloud now.
2. Check the drive with the manufacturer's tool (Samsung Magician, WD Dashboard, Crucial Storage Executive, SeaTools) or CrystalDiskInfo.
3. Plan to replace the drive. Under warranty, the manufacturer's tool report helps with the claim.
:::
::: status Ok,Unknown,Info,Unsupported
No action needed.
:::

## How to check the fix
After replacing the drive, run the scan again.
