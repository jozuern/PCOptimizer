# Ethernet slower than the adapter supports

## Summary
::: variant forced
{{adapter}} is fixed to {{link}} in the driver, but supports {{max}}. Set it back to auto negotiation.
:::
::: variant negotiated
{{adapter}} connects at only {{link}} although it supports {{max}}: a cable or plug problem, or a router or switch port that only supports 100 Mbit/s.
:::
::: variant default
Checks whether the wired network connection runs at the speed the adapter supports.
:::

## Why it matters
Downloads and game updates are limited to the link speed. A link that only reaches 100 Mbit/s on a gigabit adapter is usually a cable, plug, wall socket or switch port problem; a faulty Cat 5e or Cat 6 cable often still works at 100 Mbit/s [3]. Power saving options of the driver can also lower the link speed [2]. A faulty cable can also cause packet loss, which shows in games as rubber banding. Ping itself barely changes with link speed.

## How we detected it
We read the current link speed from Windows and the speeds the driver offers in its **Speed & Duplex** setting (the name can differ by driver), plus the current value of that setting [1]. A 2.5 Gbit/s adapter on a 1 Gbit/s router is normal and not reported.

## How to fix
::: variant forced
1. Use the one-click fix: it sets **Speed & Duplex** back to **Auto Negotiation** and restarts the adapter (the connection drops for a few seconds). Undo restores the previous value.
2. Or set it in Device Manager > Network adapters > {{adapter}} > Advanced > Speed & Duplex.
:::
::: variant negotiated
1. Replace the network cable with a Cat 5e or better cable and check that both plugs click in.
2. Try another port on the router or switch. Some ports or older switches only support 100 Mbit/s.
3. If a wall socket is in between, the wiring or the socket there can be the limit [3].
4. Check the adapter's Advanced tab in Device Manager for power saving options that lower the speed, for example Reduce Speed On Power Down (names vary by driver), and on the Power Management tab the option that lets Windows turn off the device to save power [2].
:::
::: variant default
No action needed.
:::

## How to check the fix
Run the scan again. The link speed should match the adapter maximum, or the maximum of your router.
