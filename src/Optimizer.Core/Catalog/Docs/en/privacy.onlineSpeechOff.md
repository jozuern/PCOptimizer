# Online speech recognition off

## Summary
Turns off cloud-based speech recognition. Voice typing and voice access then work only with offline features.

## How it works
The policy "Allow users to enable online speech recognition services" is set to off [1].

## Why it can help
Less data leaves this PC. No measurable effect on performance.

## Evidence
Privacy setting; it does not change frame rate or latency.

## Trade-offs & risks
Dictation in apps that use Microsoft's online speech service stops working.

## When not to use it
If you use voice typing.
