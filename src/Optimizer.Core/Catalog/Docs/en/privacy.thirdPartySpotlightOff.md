# Windows Spotlight: no third-party suggestions

## Summary
Spotlight, Start and Windows tips no longer suggest apps and content from other companies. Spotlight pictures stay. Pro, Enterprise and Education.

## How it works
The user policy "Do not suggest third-party content in Windows spotlight" (DisableThirdPartySuggestions = 1) stops app and content suggestions from third-party software publishers in Spotlight features such as the lock screen, suggested apps in Start and Windows tips; suggestions for Microsoft features, apps and services can still appear [1]. Microsoft lists it for Pro, Enterprise and Education [1].

## Why it can help
Fewer promotions on the lock screen and in Windows. A privacy setting without effect on frame rate or latency.

## Evidence
A documented Windows policy [1].

## Trade-offs & risks
None beyond missing these suggestions.

## When not to use it
If you like app suggestions from other companies.
