# Secure Boot certificates from 2023

## Summary
::: status Info
The 2023 Secure Boot certificates are not fully installed. Booting still works, but future boot security updates need them.
:::
::: status Ok
The 2023 Secure Boot certificates are installed.
:::
::: status Unknown,Problem,Unsupported
Checks whether the firmware has Microsoft's 2023 Secure Boot certificates, which replace the 2011 ones.
:::

## Why it matters
Secure Boot only starts boot software signed by certificates stored in the firmware. Microsoft's original certificates from 2011 expire in 2026 [1]. PCs need the new 2023 certificates in the KEK and db lists to keep receiving updates for the Windows boot manager and the Secure Boot block lists. A PC without them keeps booting, and anti-cheats that require Secure Boot keep working, but it stops getting these security fixes. This has no effect on game performance.

## How we detected it
We read the firmware's KEK and db variables (read-only, needs administrator rights) and search them for the names of the 2023 certificates. We also show the status Windows Update reports for the certificate update.
::: variant notElevated
Start the app as administrator to read the firmware variables.
:::

## How to fix
1. Install all Windows updates. Microsoft rolls the new certificates out through Windows Update [1].
2. If the status stays the same after updates and restarts, install the latest BIOS for your {{board}}. Some boards need a firmware update before Windows can write the new certificates.
3. Do not change Secure Boot keys manually unless the board manufacturer tells you to.

## How to check the fix
Run the scan again as administrator. KEK CA 2023 and Windows UEFI CA 2023 should show "Present".
