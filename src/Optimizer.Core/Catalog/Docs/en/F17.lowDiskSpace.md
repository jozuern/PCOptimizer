# Low free space on a drive

## Summary
::: status Problem
Drive {{volume}} has less than 10 % free space. Windows updates, game updates, the page file and shader caches need room to work.
:::
::: status Ok,Unknown,Info,Unsupported
Checks that each drive keeps at least 10 % free space.
:::

## Why it matters
A nearly full system drive leaves too little room for the page file, Windows updates and temporary files; updates can fail and the system can stall when memory runs short. Games need free space to install patches, which often need the full game size again for a short time, and to store shader caches. On SSDs, free space also gives the controller room to keep write speed up.

## How we detected it
We read size and free space of every fixed drive. Less than 10 % free counts as low (threshold in the catalog).

## How to fix
1. Open **Settings > System > Storage** and run **Cleanup recommendations**.
2. Uninstall games you no longer play, or move them to another drive.
3. Empty the Recycle Bin and delete old downloads.
4. A Cleanup module in a later version of this app will show sizes per category before deleting.

## How to check the fix
Run the scan again. The drive should show at least 10 % free.
