# Low free space on a drive

## Summary
::: status Problem
::: variant system
The system drive {{volume}} has less than 10 % free space. Windows updates, the page file and temporary files need room to work.
:::
::: variant games,default
Drive {{volume}} holds a game library and has less than 10 % free space. Game updates and shader caches need room to work.
:::
:::
::: status Info
Drive {{volume}} has less than 10 % free space. It holds neither Windows nor a game library, so games are not affected.
:::
::: status Ok,Unknown,Unsupported
Checks that the system drive and the drives with game libraries keep at least 10 % free space.
:::

## Why it matters
When a PC runs low on storage, performance can drop and Windows updates can fail to install [1]. A nearly full system drive also leaves too little room for the page file and temporary files. Games need free space to install patches and to store shader caches. On SSDs, free space also gives the controller room for its background work.
::: status Info
A data or backup drive that is nearly full does not slow down Windows or games. Keep an eye on it if you still write to it.
:::

## How we detected it
We read size and free space of every fixed drive with a drive letter. Less than 10 % free counts as low; that threshold is our own rule of thumb (set in the catalog), not a Microsoft value. The system drive and drives that hold a Steam or Xbox game library count as a problem, other drives as information. External USB drives can appear as fixed drives too.

## How to fix
::: status Problem,Info
1. Open **Settings > System > Storage** and run **Cleanup recommendations** [1].
2. Uninstall games you no longer play, or move them to another drive.
3. Empty the Recycle Bin and delete old downloads.
4. Open the **Cleanup** page in this app; it shows the size of each category before anything is deleted.
:::
::: status Ok,Unknown,Unsupported
No action needed.
:::

## How to check the fix
Run the scan again. The drive should show at least 10 % free.
