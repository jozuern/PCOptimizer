# NVMe SSD link

## Summary
::: variant trainedDown
{{disk}} runs with fewer PCIe lanes than it supports. Reseat the drive or check whether the slot shares lanes.
:::
::: variant slotWidth,slotGen
{{disk}} sits in a slot that is slower than the drive. It works, at the slot's speed.
:::
::: variant genLower
{{disk}} currently runs at a lower PCIe generation than it supports. That can be power saving at idle.
:::
::: variant default
Checks whether the NVMe SSD runs with the PCIe lanes and generation it supports.
:::

## Why it matters
An NVMe SSD normally uses four PCIe lanes. With fewer lanes, or in a slower slot, large transfers get slower: game installs, level loading and games that stream data from the drive. Frame rate itself does not change. A drive that trained down to fewer lanes than both it and the slot support usually points to a contact problem or a slot that shares lanes with another device.

## How we detected it
We read the current and maximum PCIe link of the SSD controller and, where Windows provides it, of the slot above it through the Windows device properties. The generation can drop while the drive is idle, so a lower generation alone is only information.

## How to fix
::: variant trainedDown
1. Turn off the PC, unplug it, and reseat the SSD in the M.2 slot (screw it down firmly).
2. Check the mainboard manual: some M.2 slots share lanes with SATA ports or PCIe slots and run with fewer lanes when those are in use.
3. Update the BIOS.
:::
::: variant slotWidth,slotGen
1. If the board has another M.2 slot connected to the processor, moving the drive there gives full speed. The manual lists which slot is which.
:::
::: variant genLower
1. Run the scan again while copying a large file or loading a game. If the generation stays low, check the BIOS setting for the M.2 slot's PCIe mode (Auto is correct).
:::
::: variant default
No action needed.
:::

## How to check the fix
Run the scan again. The current link should match the drive's maximum.
