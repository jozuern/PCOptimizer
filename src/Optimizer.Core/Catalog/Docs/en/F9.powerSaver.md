# Power saver plan on a desktop PC

## Summary
::: status Problem
This desktop PC uses a power saver plan. It lowers processor clocks and responsiveness to save energy, which costs performance in games.
:::
::: status Ok,Unknown,Info,Unsupported
Checks that a desktop PC does not run a power saver plan.
:::

## Why it matters
The power saver plan limits how high and how quickly the processor raises its clock, parks cores more aggressively and slows down other devices. On a laptop on battery that is a reasonable trade-off. On a desktop it only costs performance: games react to a slower CPU with lower frame rates and worse 1 % lows. Balanced is the Windows default and works well on most desktops; High performance or Ultimate Performance keep clocks higher at idle.

## How we detected it
We read the active power plan and its base type ("personality"), so a renamed copy of the power saver plan is still recognized. The check runs only on desktops (no battery, no lid).

## How to fix
1. Open **Settings > System > Power** (or **Control Panel > Power Options**).
2. Select **Balanced** or **High performance**.
3. On an AMD Ryzen processor with 3D V-Cache on only one of two chiplets (for example 7950X3D or 9950X3D), choose **Balanced**: the AMD chipset driver needs it to send games to the right chiplet.

## How to check the fix
Run the scan again. The plan type should no longer be "Power saver".
