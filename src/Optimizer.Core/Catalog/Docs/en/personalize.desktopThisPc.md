# This PC icon on the desktop

## Summary
Shows the This PC icon on the desktop, like Settings > Personalization > Themes > Desktop icon settings.

## How it works
Desktop icon settings let you choose which icons such as This PC appear on the desktop [1]. The app sets the This PC entry under HideDesktopIcons to 0 (shown); the icon appears after you sign out and in again. Microsoft describes the switch [1] but does not document the registry value behind it; the app writes the value Windows itself stores for the switch. Until a test on real Windows confirms the effect, the tweak is a Preview.

## Why it can help
Quick access to your drives from the desktop.

## Evidence
A personal preference without effect on frame rate or latency.

## Trade-offs & risks
One more icon on the desktop.

## When not to use it
If you keep the desktop empty.
