# Laptop screen runs through the integrated GPU

## Summary
::: status Info
The built-in screen is connected to the integrated GPU. Games render on {{dgpu}} and each frame is passed over, which costs frame rate and adds delay.
:::
::: status Ok
The built-in screen is connected directly to {{dgpu}}.
:::
::: status Unknown,Problem,Unsupported
Checks which graphics chip drives the laptop's built-in screen.
:::

## Why it matters
Many gaming laptops connect the built-in screen only to the integrated GPU to save power (NVIDIA Optimus, AMD hybrid graphics). The dedicated GPU renders the game and passes every frame to the integrated GPU for display [1]. That costs frame rate and adds delay; NVIDIA reports 11 to 27 % higher frame rates and up to 22 % lower latency in its own tests when the integrated GPU is bypassed [1]. Laptops with a MUX switch or NVIDIA Advanced Optimus can connect the screen directly to the dedicated GPU [1].

## How we detected it
We read which graphics adapter each active display is connected to through the Windows display configuration. A display counts as the built-in screen when Windows reports an internal connection, including embedded DisplayPort and embedded UDI [2].

## How to fix
1. Check whether your laptop has a MUX switch or Advanced Optimus: look in the manufacturer's control software (for example "GPU mode", "Ultimate" or "dGPU only") or the display mode setting in the NVIDIA Control Panel.
2. If it does, choose the dedicated GPU mode while gaming and restart if asked.
::: if externalOnDgpu
3. An external monitor on {{externalOnDgpu}} is already connected directly to the dedicated GPU.
:::
::: ifnot externalOnDgpu
3. Many laptops wire the HDMI or a USB-C/DisplayPort output directly to the dedicated GPU; an external monitor there avoids the copy.
:::

## How to check the fix
Run the scan again after switching the mode.
