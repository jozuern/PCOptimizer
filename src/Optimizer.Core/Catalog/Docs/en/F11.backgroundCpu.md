## Why it matters
Processor time used in the background is missing from the game, mostly as lower minimum frame rates and occasional stutter. Typical causes are updaters, cloud sync, browser tabs, game launchers downloading updates, and RGB or monitoring tools that poll sensors often.
::: if defender
Microsoft Defender (MsMpEng) was scanning. That is normal after updates or downloads and stops on its own; do not turn off Defender for gaming.
:::

## How we detected it
We measured the processor time of every process over three seconds during the scan, while only this app was in front. Programs above 5 % of the total processor time are listed; essential Windows processes are left out.

## How to fix
1. Close programs you do not need while playing, or let launchers finish their downloads before you start a game.
2. Check the program's settings for "start with Windows" and background activity, or turn it off on the **Startup** page.
3. If a program uses the processor all the time without reason, update or reinstall it.

## How to check the fix
Run the scan again with the same programs open.
