# Graphics driver older than six months

## Summary
::: status Problem
The driver for {{gpu}} is more than six months old. Newer drivers contain fixes and optimizations for current games.
:::
::: status Info
::: variant legacy
{{gpu}} is graphics its maker no longer releases drivers for, so the installed driver stays the newest one.
:::
::: variant default
Checks that the graphics driver is less than about six months old.
:::
:::
::: status Ok,Unknown,Unsupported
Checks that the graphics driver is less than about six months old.
:::

## Why it matters
GPU vendors release driver updates for new games, often with performance fixes for specific titles and fixes for crashes or graphical errors. A driver that is many months old misses these. A newer driver does not make every game faster, and the effect is usually small in older games. A clean, current driver is still the basis for the other checks in this app.
::: variant legacy
NVIDIA ended Game Ready drivers for its Kepler desktop GPUs (GeForce GTX 600 and 700 series, GT 630 to 740, GTX TITAN) in October 2021 and security updates in September 2024 [2][3]. AMD moved the Radeon HD 5000 to 8000, R5, R7 and R9 200 and 300 series, R9 Fury and Nano and the APUs with Radeon R2 to R7 Graphics to legacy support with no further driver releases [4]. For such graphics an old driver date says nothing about a missing update.
:::

## How we detected it
We read the driver date and version of each graphics adapter from Windows (WMI, Win32_VideoController) [1]. For NVIDIA cards, the Windows version number (for example 32.0.16.1742) is converted to the NVIDIA version (617.42). The six month limit is our own rule of thumb, not a vendor recommendation. On desktops with a graphics card, an integrated GPU that drives no display is not checked. Some laptop makers only release tested drivers for their models; there the newest driver from the GPU vendor may not install. Graphics on the vendors' legacy lists [2][3][4], recognized by name, get information instead of a problem.

## How to fix
::: variant legacy
Nothing to update: the driver you have is the last one for this graphics. Games that need a newer driver need newer graphics.
:::
::: variant default
::: if vendorUrl
1. Download the current driver from the vendor: {{vendorUrl}}
:::
::: ifnot vendorUrl
1. Download the current driver from the website of the graphics card or PC maker.
:::
1. Install it. A "clean install" option (NVIDIA: Custom > Perform a clean installation; AMD: Factory reset) removes old profile settings. Only use it if you do not need your current driver settings.
1. Restart the PC.
:::

## How to check the fix
Run the scan again. The driver age should be below 183 days.
