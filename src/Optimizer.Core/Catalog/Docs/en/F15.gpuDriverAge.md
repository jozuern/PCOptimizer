# Graphics driver older than six months

## Summary
::: status Problem
The driver for {{gpu}} is more than six months old. Newer drivers contain fixes and optimizations for current games.
:::
::: status Ok,Unknown,Info,Unsupported
Checks that the graphics driver is less than about six months old.
:::

## Why it matters
GPU vendors release driver updates for new games, often with performance fixes for specific titles and fixes for crashes or graphical errors. A driver that is many months old misses these. A newer driver does not make every game faster, and the effect is usually small in older games. A clean, current driver is still the basis for the other checks in this app.

## How we detected it
We read the driver date and version of each graphics adapter from Windows (WMI). For NVIDIA cards, the Windows version number (for example 32.0.16.1742) is converted to the NVIDIA version (617.42).

## How to fix
1. Download the current driver from the vendor: {{vendorUrl}}
2. Install it. A "clean install" option (NVIDIA: Custom > Perform a clean installation; AMD: Factory reset) removes old profile settings. Only use it if you do not need your current driver settings.
3. Restart the PC.

## How to check the fix
Run the scan again. The driver age should be below 183 days.
