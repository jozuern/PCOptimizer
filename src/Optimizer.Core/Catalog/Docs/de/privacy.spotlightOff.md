# Windows-Blickpunkt aus

## Zusammenfassung
Schaltet alle Blickpunkt-Funktionen auf einmal aus, auch Blickpunkt auf dem Sperrbildschirm, Windows-Tipps und Consumerfeatures. Microsoft unterstützt das nur auf Enterprise und Education.

## So funktioniert es
Die Benutzerrichtlinie "Alle Windows-Blickpunkt-Features deaktivieren" (DisableWindowsSpotlightFeatures = 1) schaltet Blickpunkt auf dem Sperrbildschirm, Windows-Tipps, Microsoft-Consumerfeatures und verwandte Funktionen auf einmal aus; Microsoft empfiehlt sie, um den Netzwerkverkehr gering zu halten [1][2]. Microsoft unterstützt die Blickpunkt-Richtlinien nur auf Enterprise und Education, deshalb bietet die App die Option nur dort an [1].

## Warum es helfen kann
Keine heruntergeladenen Bilder, Tipps oder Werbung für Sperrbildschirm und Desktop. Eine Datenschutzeinstellung ohne Einfluss auf Bildrate oder Latenz.

## Belege
Eine von Microsoft beschriebene Windows-Richtlinie [1][2].

## Nachteile & Risiken
Du wählst dein eigenes Sperrbildschirmbild statt des täglichen Blickpunkt-Bilds.

## Wann du es nicht nutzen solltest
Wenn du die täglichen Blickpunkt-Bilder magst.
