# Altlasten anderer Tweak-Tools

## Zusammenfassung
::: status Problem
Die Startoption useplatformclock ist gesetzt. Ältere Tweak-Anleitungen setzen sie. Jede Zeitstempel-Abfrage nutzt dann einen langsameren Timer.
:::
::: status Ok,Unknown,Info,Unsupported
Prüft auf Startoptionen anderer Tweak-Tools, die Zeitstempel-Abfragen auf aktuellen PCs verlangsamen.
:::

## Warum das wichtig ist
Programme und Spiele fragen Windows viele Male pro Bild nach genauen Zeitstempeln. Normalerweise antwortet Windows aus dem Zeitstempelzähler des Prozessors (TSC), was zehn bis einige hundert Prozessortakte dauert, und weicht nur dort auf einen Plattform-Timer (HPET oder ACPI-PM-Timer) aus, wo der TSC nicht geeignet ist [2]. Die Startoption useplatformclock erzwingt den Plattform-Timer, für den Microsoft etwa 0,8 bis 1,0 µs plus einen Systemaufruf pro Abfrage angibt [2]. Microsoft dokumentiert die Option nur für die Fehlersuche [1].

## Wie wir es erkennen
Wir lesen den Starteintrag {current} mit bcdedit. Das braucht Administratorrechte, ohne sie ist das Ergebnis unbekannt. Jeder Wert von useplatformclock zählt als Altlast, weil Windows die Option nie selbst setzt.

## So behebst du es
Unter Tweaks > Altlasten gibt es „Erzwungene Plattformuhr entfernen“. Das ist eine Experten-Änderung, weil sie die Startkonfiguration betrifft. Halte BitLocker vorher an, wenn dein Systemlaufwerk damit verschlüsselt ist.

## So prüfst du die Behebung
Starte den PC neu und führe den Scan erneut aus. Die Liste sollte leer sein.
