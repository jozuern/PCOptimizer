# Symbol Dieser PC auf dem Desktop

## Zusammenfassung
Zeigt das Symbol Dieser PC auf dem Desktop, wie Einstellungen > Personalisierung > Designs > Desktopsymboleinstellungen.

## So funktioniert es
In den Desktopsymboleinstellungen wählst du, welche Symbole wie Dieser PC auf dem Desktop erscheinen [1]. Die App setzt den Eintrag für Dieser PC unter HideDesktopIcons auf 0 (sichtbar); das Symbol erscheint nach dem Ab- und erneuten Anmelden. Microsoft beschreibt den Schalter [1], der Registry-Wert dahinter ist aber nicht dokumentiert; die App schreibt denselben Wert, den Windows beim Umlegen des Schalters speichert. Auf einer echten Windows-11-Installation (26H2) haben wir geprüft: Die Änderung wirkt, und Rückgängig machen stellt den alten Zustand wieder her.

## Warum es helfen kann
Schneller Zugriff auf deine Laufwerke vom Desktop aus.

## Belege
Eine persönliche Vorliebe ohne Einfluss auf Framerate oder Latenz.

## Nachteile & Risiken
Ein Symbol mehr auf dem Desktop.

## Wann du es nicht nutzen solltest
Wenn du den Desktop leer hältst.
