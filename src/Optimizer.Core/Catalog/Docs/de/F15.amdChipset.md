# AMD Chipset Software nicht installiert

## Zusammenfassung
::: status Problem
AMD Chipset Software fehlt. Auf dem {{cpu}} installiert sie den 3D-V-Cache-Treiber, der Spiele auf den Cache-Chip legt. Installiere sie.
:::
::: status Info
AMD Chipset Software ist nicht installiert. Windows Update liefert Basistreiber, AMDs Paket ist aber der aktuelle und vollständige Satz.
:::
::: status Ok
AMD Chipset Software ist installiert.
:::
::: status Unknown,Unsupported
Prüft, ob AMDs Chipsatz-Treiberpaket installiert ist.
:::

## Warum das wichtig ist
AMDs Chipsatzpaket enthält die Treiber für die Chipsatzfunktionen des Mainboards und die Einstellungen für die Energieverwaltung der Ryzen-Prozessoren [1].
::: variant x3d
Bei Prozessoren mit 3D V-Cache auf nur einem von zwei Chips installiert das Paket zusätzlich den Treiber „AMD 3D V-Cache Performance Optimizer“. Zusammen mit dem Spielmodus und dem Plan „Ausbalanciert“ parkt er während eines Spiels die Kerne ohne den zusätzlichen Cache, damit das Spiel auf dem Cache-Chip läuft. Ohne ihn landen Spiele unter Umständen auf dem falschen Chip und verlieren Bildrate.
:::

## Wie wir es erkennen
Wir suchen in der Liste der installierten Programme nach „AMD Chipset Software“ (oder den älteren Paketnamen). Treiber aus Windows Update tauchen dort nicht auf. „Nicht installiert“ heißt also nur, dass AMDs Paket fehlt.

## So behebst du es
1. Lade **AMD Chipset Software** für deinen Chipsatz von AMDs Treiberseite [1] (oder von der Supportseite deines Mainboards).
2. Installiere sie und starte neu.
::: variant x3d
3. Behalte den Plan **Ausbalanciert** und den Spielmodus bei, damit der V-Cache-Treiber die Kerne parken kann.
:::

## So prüfst du die Behebung
Starte den Scan erneut. Das Paket sollte mit seiner Version erscheinen.
