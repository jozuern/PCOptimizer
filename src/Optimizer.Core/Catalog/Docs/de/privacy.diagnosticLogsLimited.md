# Diagnoseprotokolle und Speicherabbilder begrenzen

## Zusammenfassung
Verhindert, dass Windows mit optionalen Diagnosedaten zusätzliche Protokolle und vollständige Speicherabbilder hochlädt.

## So funktioniert es
Zwei Richtlinien begrenzen, was optionale Diagnosedaten enthalten dürfen: keine zusätzlichen Diagnoseprotokolle und nur kleine Absturzabbilder [1].

## Warum es helfen kann
Weniger Daten verlassen diesen PC. Kein messbarer Einfluss auf die Leistung.

## Belege
Datenschutzeinstellung; sie ändert weder Bildrate noch Latenz.

## Nachteile & Risiken
Microsoft erhält weniger Details, um Abstürze auf deinem PC zu analysieren.

## Wann du es nicht nutzen solltest
Wenn der Microsoft-Support dich um vollständige Diagnosedaten bittet.
