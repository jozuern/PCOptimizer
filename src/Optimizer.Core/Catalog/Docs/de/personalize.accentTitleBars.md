# Akzentfarbe auf Titelleisten

## Zusammenfassung
Zeigt deine Akzentfarbe auf Titelleisten und Fensterrändern, wie der Schalter unter Einstellungen > Personalisierung > Farben.

## So funktioniert es
Die Option "Akzentfarbe auf Titelleisten und Fensterrändern anzeigen" färbt die Leiste oben an jedem Fenster und seine Ränder [1]. Die App setzt ColorPrevalence auf 1. Microsoft beschreibt den Schalter [1], der Registry-Wert dahinter ist aber nicht dokumentiert; die App schreibt den Wert, den Windows selbst für den Schalter speichert. Bis ein Test unter echtem Windows die Wirkung bestätigt, ist die Option eine Vorschau.

## Warum es helfen kann
Das aktive Fenster ist leichter zu erkennen.

## Belege
Eine persönliche Vorliebe ohne Einfluss auf Bildrate oder Latenz.

## Nachteile & Risiken
Keine außer der Optik.

## Wann du es nicht nutzen solltest
Wenn dir neutrale Titelleisten lieber sind.
