# Laptop-Bildschirm läuft über die integrierte GPU

## Zusammenfassung
::: status Info
Der eingebaute Bildschirm hängt an der integrierten GPU. Spiele rechnet die {{dgpu}}, die Bilder werden umkopiert. Das kostet etwas FPS und Verzögerung.
:::
::: status Ok
Der eingebaute Bildschirm hängt direkt an der {{dgpu}}.
:::
::: status Unknown,Problem,Unsupported
Prüft, welcher Grafikchip den eingebauten Bildschirm des Laptops ansteuert.
:::

## Warum das wichtig ist
Viele Gaming-Laptops verbinden den eingebauten Bildschirm zum Stromsparen nur mit der integrierten GPU (NVIDIA Optimus, AMD-Hybridgrafik). Die dedizierte GPU berechnet das Spiel, und jedes Bild wird zur Anzeige zur integrierten GPU kopiert. Das kostet einige Prozent Bildrate und etwas Verzögerung, bei hohen Bildraten mehr. Laptops mit MUX-Schalter oder NVIDIA Advanced Optimus können den Bildschirm direkt mit der dedizierten GPU verbinden [1].

## Wie wir es erkennen
Wir lesen über die Windows-Anzeigekonfiguration, an welchem Grafikadapter jeder aktive Bildschirm hängt.

## So behebst du es
1. Prüfe, ob dein Laptop einen MUX-Schalter oder Advanced Optimus hat: Sieh in der Steuersoftware des Herstellers nach (zum Beispiel „GPU-Modus“, „Ultimate“ oder „dGPU only“) oder in der NVIDIA Systemsteuerung > Anzeigemodus.
2. Wenn ja, wähle beim Spielen den Modus für die dedizierte GPU und starte neu, falls verlangt.
::: if externalOnDgpu
3. Ein externer Monitor an {{externalOnDgpu}} hängt bereits direkt an der dedizierten GPU.
:::
::: ifnot externalOnDgpu
3. Bei vielen Laptops ist der HDMI- oder ein USB-C/DisplayPort-Ausgang direkt mit der dedizierten GPU verbunden. Ein externer Monitor dort vermeidet das Umkopieren.
:::

## So prüfst du die Behebung
Starte den Scan nach dem Umschalten erneut.
