# Laptop-Bildschirm läuft über die integrierte GPU

## Zusammenfassung
::: status Info
Der eingebaute Bildschirm hängt an der integrierten GPU. Spiele rechnet die {{dgpu}}, jedes Bild wird weitergereicht. Das kostet Bildrate und Verzögerung.
:::
::: status Ok
Der eingebaute Bildschirm hängt direkt an der {{dgpu}}.
:::
::: status Unknown,Problem,Unsupported
Prüft, welcher Grafikchip den eingebauten Bildschirm des Laptops ansteuert.
:::

## Warum das wichtig ist
Viele Gaming-Laptops verbinden den eingebauten Bildschirm zum Stromsparen nur mit der integrierten GPU (NVIDIA Optimus, AMD-Hybridgrafik). Die dedizierte GPU berechnet das Spiel und reicht jedes Bild zur Anzeige an die integrierte GPU weiter [1]. Das kostet Bildrate und Verzögerung; NVIDIA nennt in eigenen Tests 11 bis 27 % mehr FPS und bis zu 22 % weniger Latenz, wenn die integrierte GPU umgangen wird [1]. Laptops mit MUX-Schalter oder NVIDIA Advanced Optimus können den Bildschirm direkt mit der dedizierten GPU verbinden [1].

## Wie wir es erkennen
Wir lesen über die Windows-Anzeigekonfiguration, an welchem Grafikadapter jeder aktive Bildschirm hängt. Als eingebauter Bildschirm gilt eine Anzeige, für die Windows einen internen Anschluss meldet, auch Embedded DisplayPort und Embedded UDI [2].

## So behebst du es
1. Prüfe, ob dein Laptop einen MUX-Schalter oder Advanced Optimus hat: Sieh in der Steuersoftware des Herstellers nach (zum Beispiel „GPU-Modus“, „Ultimate“ oder „dGPU only“) oder bei der Einstellung für den Anzeigemodus in der NVIDIA-Systemsteuerung.
2. Wenn ja, wähle beim Spielen den Modus für die dedizierte GPU und starte neu, falls verlangt.
::: if externalOnDgpu
3. Ein externer Monitor an {{externalOnDgpu}} hängt bereits direkt an der dedizierten GPU.
:::
::: ifnot externalOnDgpu
3. Bei vielen Laptops ist der HDMI- oder ein USB-C/DisplayPort-Ausgang direkt mit der dedizierten GPU verbunden. Ein externer Monitor dort vermeidet das Umkopieren.
:::

## So prüfst du die Behebung
Starte den Scan nach dem Umschalten erneut.
