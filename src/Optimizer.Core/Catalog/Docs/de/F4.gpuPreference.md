# Spiele laufen womöglich auf der integrierten Grafik

## Zusammenfassung
::: status Problem
Spiele ohne GPU-Vorgabe „Hohe Leistung“: {{count}}. Auf diesem PC mit zwei GPUs laufen sie womöglich auf der integrierten Grafik statt auf der {{dgpu}}.
:::
::: status Ok,Unknown,Info,Unsupported
Prüft, ob Spiele auf PCs, die auch eine integrierte Grafik haben, die eigene Grafikkarte nutzen.
:::

## Warum das wichtig ist
Auf Laptops mit Hybridgrafik und auf Desktops mit eingeschalteter Prozessorgrafik entscheidet Windows pro App, welche GPU sie berechnet. Ohne Vorgabe starten manche Spiele auf der stromsparenden integrierten GPU und laufen nur mit einem Bruchteil der FPS.

## Wie wir es erkennen
Wir lesen die installierten Steam-Spiele (appmanifest-Dateien), ermitteln die vermutliche Haupt-exe jedes Spiels und lesen deine GPU-Vorgaben pro App (UserGpuPreferences). Ein Spiel ohne GpuPreference=2 zählt als fehlend. Bei Spielen, die über einen Launcher starten, kann die ermittelte exe falsch sein.

## So behebst du es
Nutze die Ein-Klick-Lösung, um für die gelisteten Spiele „Hohe Leistung“ zu setzen, oder stelle es pro Spiel unter Einstellungen > System > Bildschirm > Grafik ein.

## So prüfst du die Behebung
Starte den Scan erneut. Bei laufendem Spiel zeigt der Task-Manager unter Leistung > GPU, welche GPU arbeitet.
