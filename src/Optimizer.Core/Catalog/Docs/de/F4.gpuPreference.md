# Spiele laufen womöglich auf der integrierten Grafik

## Zusammenfassung
::: status Problem,Info
Spiele ohne Windows-GPU-Vorgabe „Hohe Leistung“: {{count}}. Der Grafiktreiber legt sie womöglich schon auf die {{dgpu}}; die Vorgabe stellt das sicher.
:::
::: status Ok
Jedes erkannte Spiel hat die Windows-GPU-Vorgabe „Hohe Leistung“.
:::
::: status Unknown,Unsupported
Prüft auf PCs mit integrierter Grafik und Grafikkarte, ob Spiele eine Windows-GPU-Vorgabe haben.
:::

## Warum das wichtig ist
Auf Laptops mit Hybridgrafik und auf Desktops mit eingeschalteter Prozessorgrafik kann mehr als eine GPU ein Spiel berechnen. Fragt ein Spiel DirectX ohne Vorgabe nach einem Adapter, bekommt es zuerst den Adapter, der die Hauptanzeige ansteuert [2], und das ist bei Laptops meist die integrierte GPU. Der Grafiktreiber kann das Spiel trotzdem auf die Grafikkarte legen: NVIDIAs Treiberprofile teilen dem System mit, welche Spiele die GeForce-GPU brauchen [1]. Landet ein Spiel doch auf der integrierten GPU, läuft es mit deutlich weniger FPS. Die Windows-Vorgabe „Hohe Leistung“ fordert für diese App die leistungsstärkste GPU an [3].

## Wie wir es erkennen
Wir lesen die installierten Steam-Spiele (appmanifest-Dateien), ermitteln die vermutliche Haupt-exe jedes Spiels und lesen deine GPU-Vorgaben pro App in Windows (die Liste hinter Einstellungen > System > Bildschirm > Grafik). Ein Spiel ohne die Vorgabe „Hohe Leistung“ zählt als fehlend. Ob der NVIDIA- oder AMD-Treiber ein Spiel schon über ein eigenes Profil auf die Grafikkarte legt, sehen wir nicht, und wir messen nicht, welche GPU ein laufendes Spiel nutzt. Das ist also eine Vorsichtsmaßnahme, kein Beweis, dass ein Spiel auf der falschen GPU läuft. Bei Spielen, die über einen Launcher starten, kann außerdem die ermittelte exe falsch sein.

## So behebst du es
::: status Problem,Info
Nutze die Ein-Klick-Lösung, um für die gelisteten Spiele „Hohe Leistung“ zu setzen, oder stelle es pro Spiel unter **Einstellungen > System > Bildschirm > Grafik** ein.
:::
::: status Ok,Unknown,Unsupported
Nichts zu tun.
:::

## So prüfst du die Behebung
Starte den Scan erneut. Bei laufendem Spiel zeigt der Task-Manager unter Leistung > GPU, welche GPU arbeitet.
