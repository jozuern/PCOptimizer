# Personalisierung von Freihand und Eingabe aus

## Zusammenfassung
Verhindert, dass Windows deine Eingaben und Handschrift für ein persönliches Wörterbuch sammelt, und schaltet Eingabe-Einblicke ab.

## So funktioniert es
Richtlinien beenden das automatische Lernen aus getipptem Text und Handschrift; die Benutzereinstellungen beenden das Sammeln von Kontakten für Vorschläge und schalten Eingabe-Einblicke ab [1][2].

## Warum es helfen kann
Weniger Daten verlassen diesen PC. Kein messbarer Einfluss auf die Leistung.

## Belege
Datenschutzeinstellung; sie ändert weder Bildrate noch Latenz.

## Nachteile & Risiken
Textvorschläge und Handschrifterkennung lernen weniger von dir.

## Wann du es nicht nutzen solltest
Wenn du viel mit einem Stift schreibst.
