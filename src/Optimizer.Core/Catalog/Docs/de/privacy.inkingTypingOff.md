# Personalisierung von Freihand und Eingabe aus

## Zusammenfassung
Verhindert, dass Windows aus deinen Eingaben und deiner Handschrift lernt und Freihand- und Eingabedaten an Microsoft sendet.

## So funktioniert es
Die Richtlinie „Automatisches Lernen deaktivieren“ verhindert, dass Windows getippten Text und Handschrift für dein persönliches Wörterbuch sammelt, und löscht die bisher gespeicherten Daten [3]. Die Richtlinie „Verbessern Sie die Freihand- und Tipperkennung“ wird abgeschaltet, damit keine Freihand- und Eingabedaten mehr an Microsoft gehen [1][2]. Zwei Benutzerschalter beenden das Sammeln von Kontakten für Vorschläge und schalten Eingabe-Einblicke ab; diese beiden Werte dokumentiert Microsoft nicht.

## Warum es helfen kann
Weniger Daten verlassen diesen PC. Kein messbarer Einfluss auf die Leistung.

## Belege
Datenschutzeinstellung; sie ändert weder Bildrate noch Latenz.

## Nachteile & Risiken
Textvorschläge und Handschrifterkennung lernen weniger von dir, und das bisher aufgebaute persönliche Wörterbuch wird gelöscht.

## Wann du es nicht nutzen solltest
Wenn du viel mit einem Stift schreibst.
