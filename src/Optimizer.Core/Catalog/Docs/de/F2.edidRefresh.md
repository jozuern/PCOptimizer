# Monitor kann mehr, als Windows anbietet

## Zusammenfassung
::: status Problem
{{display}} meldet bis zu {{edidMax}} Hz, Windows bietet aber höchstens {{offered}} Hz an. Die Verbindung oder eine Monitoreinstellung begrenzt das.
:::
::: status Ok
Windows bietet die Bildwiederholraten an, die {{display}} meldet.
:::
::: status Unknown,Info,Unsupported
Vergleicht die höchste Bildwiederholrate, die der Monitor meldet (EDID), mit der höchsten, die Windows für ihn anbietet.
:::

## Warum das wichtig ist
Windows bietet nur Anzeigemodi an, die Monitor, Kabel, beide Anschlüsse und der Grafiktreiber gemeinsam unterstützen. Meldet der Monitor selbst eine deutlich höhere Rate als jeder angebotene Modus, bremst ein Glied dieser Kette. Jeder Anschlusstyp und jede Kabelklasse hat eine maximale Bandbreite; HDMI-Kabel werden zum Beispiel für eine bestimmte Bandbreite zertifiziert [2]. Bei 144 Hz kann alle 6,9 ms ein neues Bild erscheinen, bei 60 Hz nur alle 16,7 ms.

## Wie wir es erkennen
Wir lesen die Frequenzgrenzen aus den EDID-Daten des Monitors (der Datenblock, den jeder Monitor sendet) und die Liste der Modi, die Windows für diesen Bildschirm bei allen Auflösungen anbietet. Windows meldet außerdem den Anschlusstyp jedes Bildschirms (HDMI, DVI, DisplayPort, VGA oder intern) [1]. Ein Problem melden wir nur, wenn das EDID-Maximum mindestens 75 Hz beträgt und mindestens 20 % über dem höchsten angebotenen Modus liegt. Manche Monitore geben ein etwas höheres Maximum an, als sie bei voller Auflösung zeigen, und manche nennen ihre höchsten Raten nur in einem Erweiterungsblock, den wir nicht lesen. Nimm das also als starken Hinweis, nicht als Beweis.

## So behebst du es
::: variant hdmi,dvi,vga
1. Schließe den Monitor per **DisplayPort** an, wenn Monitor und Grafikkarte das haben. Ältere Anschlusstypen übertragen weniger Bandbreite und schaffen hohe Bildwiederholraten bei hohen Auflösungen unter Umständen nicht.
:::
1. Nutze das Kabel, das beim Monitor dabei war, oder ein zertifiziertes Kabel für die nötige Bandbreite (für HDMI-2.1-Raten ein Ultra High Speed HDMI-Kabel [2]).
1. Öffne das Menü des Monitors und suche nach Einstellungen, die den Eingang begrenzen, zum Beispiel eine auf 1.1 gestellte DisplayPort-Version, einen HDMI-Modus 1.4 oder eine ausgeschaltete „Overclock“-Option.
1. Bietet Windows die Rate immer noch nicht an, installiere den Monitortreiber (INF-Datei) des Herstellers.
1. Wähle die Rate danach unter **Einstellungen > System > Bildschirm > Erweiterte Anzeige**.

## So prüfst du die Behebung
Starte den Scan erneut. Windows sollte jetzt die höhere Rate anbieten, und die Prüfung der Bildwiederholrate zeigt, ob sie eingestellt ist.
