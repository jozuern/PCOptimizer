# Globale NVIDIA-Einstellungen bremsen jedes Spiel

## Zusammenfassung
::: status Problem
Eine globale NVIDIA-Einstellung bremst jedes Spiel: ein niedriges Bildratenlimit oder der auf Minimum gestellte Energiemodus. Ein Klick setzt sie auf den Treiberstandard zurück.
:::
::: status Info
V-Sync ist global ohne G-SYNC erzwungen. Das verhindert Tearing, verzögert aber jedes Spiel.
:::
::: status Ok
Das globale NVIDIA-Profil enthält keine Einstellung, die Spiele begrenzt.
:::
::: status Unknown,Unsupported
Prüft das globale NVIDIA-Profil auf Einstellungen, die alle Spiele begrenzen.
:::

## Warum das wichtig ist
Einstellungen unter **NVIDIA-Systemsteuerung > 3D-Einstellungen verwalten > Globale Einstellungen** gelten für jedes Spiel ohne eigenen Wert. Tools und Anleitungen hinterlassen dort manchmal Werte, die überall Leistung kosten.
::: if lowCap
Ein globales Bildratenlimit von {{cap}} FPS an einem {{refresh}}-Hz-Bildschirm begrenzt jedes Spiel weit unter das, was der Bildschirm zeigen kann. Ein Limit wenige FPS unter der Bildwiederholrate ist in Ordnung und die übliche G-SYNC-Einstellung, daher melden wir nur deutlich niedrigere Limits.
:::
::: if powerMin
Der Energieverwaltungsmodus „Minimale Leistung bevorzugen“ hält die Grafikkarte auf niedrigen Takten. Meist setzen ihn Fremdtools, die Treiberprofile bearbeiten.
:::
::: if vsyncForced
Erzwungenes V-Sync wartet vor jedem neuen Bild auf den Bildschirm. Ohne G-SYNC verhindert das Tearing, kostet aber bis zu einen Bildwechsel Verzögerung. Mit G-SYNC ist erzwungenes V-Sync zusammen mit einem Bildratenlimit mindestens 3 FPS unter der Bildwiederholrate die Einstellung, die die Latenztests von Blur Busters (eine unabhängige Testseite) empfehlen [1].
:::

## Wie wir es erkennen
Wir lesen das globale Profil (das Basisprofil der Treibereinstellungen) über NVIDIAs dokumentierte Schnittstelle für Treibereinstellungen (NVAPI DRS) [2] und den G-SYNC-Status jedes Bildschirms. Es zählen nur Werte, die im Profil gespeichert sind; die Treiberstandards sind in Ordnung.

## So behebst du es
::: status Problem
1. Nutze die Ein-Klick-Behebung: Sie entfernt den eigenen Wert des globalen Profils für die oben genannten Einstellungen, damit der Treiberstandard gilt. Rückgängig machen stellt deine Werte wieder her.
2. Wenn du ein Bildratenlimit für G-SYNC willst, setze es wenige FPS unter die Bildwiederholrate.
:::
::: status Info
1. Wenn dich Tearing nicht stört, stelle **Vertikale Synchronisierung** in der NVIDIA-Systemsteuerung > 3D-Einstellungen verwalten auf **Einstellung der 3D-Anwendung verwenden**.
2. Unterstützt der Monitor G-SYNC oder G-SYNC Compatible, schalte stattdessen das ein (siehe die Prüfung der variablen Bildwiederholrate).
:::
::: status Ok,Unknown,Unsupported
Nichts zu tun.
:::

## So prüfst du die Behebung
Starte den Scan erneut. Die Werte oben sollten die Treiberstandards zeigen.
