# Laufwerkszustand

## Zusammenfassung
::: status Problem
Windows meldet ein Problem mit {{disk}}: Fehler, Abnutzung oder eine fehlgeschlagene Zustandsprüfung. Sichere jetzt deine Daten.
:::
::: status Ok
{{disk}} meldet keine Zustandsprobleme.
:::
::: status Unknown,Info,Unsupported
Zeigt den Zustand, den Windows vom Laufwerk liest (S.M.A.R.T. oder NVMe-Zustandsprotokoll).
:::

## Warum das wichtig ist
Laufwerke melden ihren eigenen Zustand: Fehler, die sie nicht korrigieren konnten, wie viel der zugesicherten Schreibmenge einer SSD verbraucht ist, und Temperaturen. Ein Laufwerk mit solchen Meldungen kann ohne weitere Warnung ausfallen, und Daten darauf können verloren gehen. Vor dem Ausfall wird es oft langsamer, was sich als lange Ladezeiten und Ruckler zeigt.

## Wie wir es erkennen
Wir lesen die Windows-Speicherverwaltung: den Zustand jedes Laufwerks und seine Zuverlässigkeitszähler (Temperatur, Abnutzung, nicht korrigierte Lese- und Schreibfehler, Betriebsstunden) [1]. Die Zähler brauchen Administratorrechte. Als Problem gilt: Zustand „Warnung“ oder „Fehlerhaft“, 90 % oder mehr Abnutzung oder ein nicht korrigierter Fehler.

## So behebst du es
::: status Problem
1. Sichere wichtige Dateien jetzt auf ein anderes Laufwerk oder in die Cloud.
2. Prüfe das Laufwerk mit dem Tool des Herstellers (Samsung Magician, WD Dashboard, Crucial Storage Executive, SeaTools) oder CrystalDiskInfo.
3. Plane den Austausch des Laufwerks. Bei Garantie hilft der Bericht des Herstellertools.
:::
::: status Ok,Unknown,Info,Unsupported
Nichts zu tun.
:::

## So prüfst du die Behebung
Starte den Scan nach dem Austausch erneut.
