# SmartScreen für Apps aus

## Zusammenfassung
Experte, Abwägung bei der Sicherheit: verhindert, dass Windows SmartScreen heruntergeladene Programme vor dem Start prüft. Kein Effekt auf die Leistung.

## So funktioniert es
Die Richtlinie EnableSmartScreen = 0 schaltet die SmartScreen-Prüfungen für Apps und Dateien in Windows ab [1].

## Warum es helfen kann
Die Meldung „Der Computer wurde durch Windows geschützt“ bei unbekannten Programmen entfällt.

## Belege
Kein Effekt auf FPS oder Ladezeiten.

## Nachteile & Risiken
Schädliche Downloads werden nicht mehr mit Microsofts Reputationsdienst abgeglichen.

## Wann du es nicht nutzen solltest
Nicht nutzen, wenn du das Risiko nicht einschätzen kannst. Meist reicht es, eine einzelne Datei in ihren Eigenschaften zuzulassen.
