# Monatliche Updates eine Woche später

## Zusammenfassung
Windows bietet die monatlichen Updates samt Sicherheitskorrekturen 7 Tage nach Erscheinen an, Probleme der ersten Tage sind dann schon bekannt. Pro, Enterprise und Education.

## So funktioniert es
Die Richtlinie für Qualitätsupdates (englisch "Select when Quality Updates are received") lässt einen PC Qualitätsupdates um bis zu 30 Tage zurückstellen [1]. Die App setzt DeferQualityUpdates = 1 und DeferQualityUpdatesPeriodInDays = 7 [1]. Funktionsupdates haben eine eigene Richtlinie und sind nicht betroffen.

## Warum es helfen kann
Ein monatliches Update, das einen Treiber, ein Spiel oder einen Anti-Cheat stört, erreicht dich eine Woche später, wenn andere schon auf das Problem gestoßen sind.

## Belege
Eine von Microsoft beschriebene Windows-Update-Richtlinie [1]. Kein Einfluss auf Framerate oder Latenz. Ob ein bestimmtes Monatsupdate ein Problem hat, ist situationsabhängig.

## Nachteile & Risiken
Auch Sicherheitskorrekturen kommen eine Woche später, eine bekannte Lücke bleibt also 7 Tage länger offen. Rückgängig entfernt die Richtlinie.

## Wann du es nicht nutzen solltest
Wenn der PC sensible Daten verarbeitet, von anderen genutzt wird oder du Sicherheitskorrekturen am Erscheinungstag willst.
