# Microsoft Edge: nur erforderliche Diagnosedaten

## Zusammenfassung
Edge sendet Microsoft nur die erforderlichen Diagnosedaten, die es sicher und aktuell halten, keine optionalen Daten über Surfen, besuchte Websites und Abstürze.

## So funktioniert es
Die Richtlinie DiagnosticData kennt drei Stufen: 0 aus, 1 erforderliche Daten, 2 optionale Daten [1]. Zu den optionalen Daten gehören die Nutzung des Browsers, besuchte Websites und Absturzberichte [1]. Die App setzt Stufe 1. Stufe 0 empfiehlt Microsoft nicht, deshalb nutzt die App sie nicht [1]. Edge übernimmt die Änderung nach einem Neustart des Browsers [1].

## Warum es helfen kann
Weniger Daten über dein Surfen verlassen diesen PC. Eine Einstellung für Datenschutz oder Bedienung; sie ändert weder Bildrate noch Latenz.

## Belege
Eine von Microsoft beschriebene Edge-Richtlinie [1]. Anders als viele Edge-Richtlinien gilt sie auch für Profile, die mit einem Microsoft-Konto angemeldet sind [1].

## Nachteile & Risiken
Microsoft bekommt weniger Absturzberichte von deinem PC, um Fehler in Edge zu finden. Weil es eine Richtlinie ist, zeigt Edge in Menü und Einstellungen an, dass es von deiner Organisation verwaltet wird, und der passende Schalter in den Edge-Einstellungen ist gesperrt. Rückgängig entfernt sie wieder.

## Wann du es nicht nutzen solltest
Wenn du Microsoft mit optionalen Daten bei der Verbesserung von Edge helfen willst oder Vorabversionen von Edge testest.
