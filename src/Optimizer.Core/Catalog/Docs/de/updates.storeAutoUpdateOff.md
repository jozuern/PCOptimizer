# Microsoft Store: keine automatischen App-Updates

## Zusammenfassung
Apps aus dem Microsoft Store, auch Store-Spiele, werden nicht mehr automatisch aktualisiert. Du aktualisierst sie selbst im Store. Pro, Enterprise und Education.

## So funktioniert es
Die Richtlinie für automatische App-Updates aus dem Microsoft Store (AutoDownload = 2 unter SOFTWARE\Policies\Microsoft\WindowsStore) schaltet den automatischen Download und die Installation von App-Updates aus [1][2].

## Warum es helfen kann
Keine Store-Downloads im Hintergrund, während du spielst oder über eine getaktete Verbindung surfst.

## Belege
Eine von Microsoft beschriebene Windows-Richtlinie [1][2]. Store-Downloads belegen Bandbreite und Datenträger nur, solange sie laufen.

## Nachteile & Risiken
Store-Apps bleiben auf alten Versionen, bis du sie aktualisierst, auch bei Sicherheitskorrekturen.

## Wann du es nicht nutzen solltest
Wenn Store-Apps ohne dein Zutun aktuell bleiben sollen.
