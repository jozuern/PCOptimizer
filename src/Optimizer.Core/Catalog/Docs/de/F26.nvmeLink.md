# Anbindung der NVMe-SSD

## Zusammenfassung
::: variant trainedDown
{{disk}} läuft mit weniger PCIe-Lanes, als sie unterstützt. Setze die SSD neu ein oder prüfe, ob sich der Steckplatz Lanes teilt.
:::
::: variant slotWidth,slotGen
{{disk}} steckt in einem Steckplatz, der langsamer ist als die SSD. Sie funktioniert, mit der Geschwindigkeit des Steckplatzes.
:::
::: variant genLower
{{disk}} läuft gerade mit einer niedrigeren PCIe-Generation, als sie unterstützt. Im Leerlauf kann das Energiesparen sein.
:::
::: variant default
Prüft, ob die NVMe-SSD mit den PCIe-Lanes und der Generation läuft, die sie unterstützt.
:::

## Warum das wichtig ist
Eine NVMe-SSD nutzt normalerweise vier PCIe-Lanes. Mit weniger Lanes oder in einem langsameren Steckplatz werden große Übertragungen langsamer: Spielinstallationen, Ladezeiten und Spiele, die Daten von der SSD nachladen. Die Bildrate selbst ändert sich nicht. Läuft eine SSD mit weniger Lanes, als sie und der Steckplatz können, liegt meist ein Kontaktproblem vor oder der Steckplatz teilt sich Lanes mit einem anderen Gerät.

## Wie wir es erkennen
Wir lesen über die Windows-Geräteeigenschaften die aktuelle und die maximale PCIe-Anbindung des SSD-Controllers und, wo Windows sie liefert, des Steckplatzes darüber. Im Leerlauf kann die Generation sinken, daher ist eine niedrigere Generation allein nur eine Information.

## So behebst du es
::: variant trainedDown
1. Schalte den PC aus, ziehe den Netzstecker und setze die SSD im M.2-Steckplatz neu ein (fest verschrauben).
2. Sieh im Handbuch des Mainboards nach: Manche M.2-Steckplätze teilen sich Lanes mit SATA-Anschlüssen oder PCIe-Steckplätzen und laufen mit weniger Lanes, wenn diese belegt sind.
3. Aktualisiere das BIOS.
:::
::: variant slotWidth,slotGen
1. Hat das Mainboard einen weiteren M.2-Steckplatz, der am Prozessor hängt, bringt die SSD dort volle Geschwindigkeit. Das Handbuch zeigt, welcher Steckplatz welcher ist.
:::
::: variant genLower
1. Starte den Scan erneut, während du eine große Datei kopierst oder ein Spiel lädst. Bleibt die Generation niedrig, prüfe im BIOS den PCIe-Modus des M.2-Steckplatzes (Auto ist richtig).
:::
::: variant default
Nichts zu tun.
:::

## So prüfst du die Behebung
Starte den Scan erneut. Die aktuelle Anbindung sollte dem Maximum der SSD entsprechen.
