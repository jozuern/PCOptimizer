# Spielebibliothek auf einer Festplatte

::: status Problem
::: variant smr
Die Spielebibliothek {{library}} liegt auf {{disk}}, einer Festplatte mit SMR-Aufzeichnung. Ladezeiten sind lang, und das Nachladen von Texturen kann ruckeln.
:::
::: variant default
Die Spielebibliothek {{library}} liegt auf einer Festplatte ({{disk}}). Spiele laden langsam und können ruckeln, wenn sie während des Spielens Daten nachladen.
:::
:::
::: status Ok

## Warum das wichtig ist
Viele aktuelle Spiele laden Texturen und Leveldaten während des Spielens nach. Eine Festplatte muss vor jedem zufälligen Zugriff warten, bis sich die Scheibe weitergedreht hat, bei 7200 U/min im Mittel etwa 4 ms, bevor sich der Kopf überhaupt bewegt [1]. Eine SSD hat keine beweglichen Teile. Spiele auf einer Festplatte zeigen deshalb lange Ladebildschirme, aufploppende Objekte und Ruckler beim Nachladen. Manche neuen Spiele setzen eine SSD voraus, zum Beispiel Starfield [2]. Festplatten mit Shingled Magnetic Recording (SMR) sind beim Schreiben großer Datenmengen noch einmal langsamer, zum Beispiel bei Installationen und Updates [3][4].
::: variant smr
Dieses Laufwerksmodell steht in der Katalogliste der SMR-Festplatten. Sie beruht auf den Listen, die Western Digital, Seagate und Toshiba veröffentlichen [3][4][5].
:::

## Wie wir es erkennen
Wir lesen die Bibliotheksordner von Steam (`libraryfolders.vdf`) und die `.GamingRoot`-Markierung der Xbox-App im Stammverzeichnis der Laufwerke. Dann ordnen wir den Laufwerksbuchstaben jeder Bibliothek dem physischen Datenträger zu und lesen den Medientyp (HDD oder SSD) aus der Windows-Speicherverwaltung. Manche USB- und RAID-Laufwerke melden keinen Medientyp; das Ergebnis ist dann unbekannt. SMR-Festplatten erkennen wir an der Modellnummer im Katalog; ein Laufwerk, das nicht in der Liste steht, kann trotzdem SMR nutzen.

## So behebst du es
::: status Problem
1. Verschiebe oft gespielte Spiele auf eine SSD. In Steam: **Einstellungen > Speicher**, Spiel auswählen, dann **Verschieben**. In der Xbox-App: **Verwalten > Dateien > Verschieben**.
2. Nutze die Festplatte für selten gespielte Spiele oder für Videos und Backups.
3. Hat das Mainboard einen freien M.2-Steckplatz, ist eine NVMe-SSD das einfachste Upgrade.
:::
::: status Ok,Unknown,Info,Unsupported
Nichts zu tun.
:::

## So prüfst du die Behebung
Starte den Scan erneut. Bei der Bibliothek sollte eine SSD als Datenträger stehen.
