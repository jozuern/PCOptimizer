# Spielebibliothek auf einer Festplatte

## Zusammenfassung
::: variant smr
Die Spielebibliothek {{library}} liegt auf {{disk}}, einer Festplatte mit SMR-Aufzeichnung. Ladezeiten sind lang, und das Nachladen von Texturen kann ruckeln.
:::
::: variant default
Die Spielebibliothek {{library}} liegt auf einer Festplatte ({{disk}}). Spiele laden langsam und können ruckeln, wenn sie während des Spielens Daten nachladen.
:::

## Warum das wichtig ist
Viele aktuelle Spiele laden Texturen und Leveldaten während des Spielens nach. Eine Festplatte braucht für einen zufälligen Zugriff mehrere Millisekunden, eine SSD nur einen Bruchteil davon. Spiele auf einer Festplatte zeigen deshalb lange Ladebildschirme, aufploppende Objekte und Ruckler beim Nachladen. Manche neuen Spiele setzen eine SSD sogar voraus. Festplatten mit Shingled Magnetic Recording (SMR) sind beim Schreiben großer Datenmengen noch einmal langsamer, zum Beispiel bei Installationen und Updates.
::: variant smr
Dieses Laufwerksmodell steht in der Katalogliste der SMR-Festplatten.
:::

## Wie wir es erkennen
Wir lesen die Bibliotheksordner von Steam (`libraryfolders.vdf`) und die `.GamingRoot`-Markierung der Xbox-App im Stammverzeichnis der Laufwerke. Dann ordnen wir den Laufwerksbuchstaben jeder Bibliothek dem physischen Datenträger zu und lesen den Medientyp (HDD oder SSD) aus der Windows-Speicherverwaltung. SMR-Festplatten erkennen wir an der Modellnummer im Katalog.

## So behebst du es
1. Verschiebe oft gespielte Spiele auf eine SSD. In Steam: **Einstellungen > Speicher**, Spiel auswählen, dann **Verschieben**. In der Xbox-App: **Verwalten > Dateien > Verschieben**.
2. Nutze die Festplatte für selten gespielte Spiele oder für Videos und Backups.
3. Hat das Mainboard einen freien M.2-Steckplatz, ist eine 1-TB-NVMe-SSD meist das Upgrade mit dem besten Preis-Leistungs-Verhältnis.

## So prüfst du die Behebung
Starte den Scan erneut. Bei der Bibliothek sollte eine SSD als Datenträger stehen.
