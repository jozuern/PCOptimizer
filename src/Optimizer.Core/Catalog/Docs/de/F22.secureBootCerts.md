# Secure-Boot-Zertifikate von 2023

## Zusammenfassung
::: status Info
Die Secure-Boot-Zertifikate von 2023 sind nicht vollständig installiert. Der Start funktioniert weiter, künftige Sicherheitsupdates für den Start brauchen sie aber.
:::
::: status Ok
Die Secure-Boot-Zertifikate von 2023 sind installiert.
:::
::: status Unknown,Problem,Unsupported
Prüft, ob die Firmware Microsofts Secure-Boot-Zertifikate von 2023 hat, die die von 2011 ablösen.
:::

## Warum das wichtig ist
Secure Boot startet nur Startsoftware, die mit Zertifikaten aus der Firmware signiert ist. Microsofts ursprüngliche Zertifikate von 2011 laufen 2026 ab [1]. PCs brauchen die neuen Zertifikate von 2023 in den Listen KEK und db, um weiter Updates für den Windows-Start-Manager und die Secure-Boot-Sperrlisten zu bekommen. Ein PC ohne sie startet weiter, und Anti-Cheats, die Secure Boot verlangen, funktionieren weiter, er bekommt aber diese Sicherheitskorrekturen nicht mehr. Auf die Spieleleistung hat das keinen Einfluss.

## Wie wir es erkennen
Wir lesen die Firmware-Variablen KEK und db (nur lesend, braucht Administratorrechte) und suchen darin nach den Namen der Zertifikate von 2023. Außerdem zeigen wir den Status, den Windows Update für das Zertifikatsupdate meldet.
::: variant notElevated
Starte die App als Administrator, um die Firmware-Variablen zu lesen.
:::

## So behebst du es
1. Installiere alle Windows-Updates. Microsoft verteilt die neuen Zertifikate über Windows Update [1].
2. Bleibt der Status nach Updates und Neustarts gleich, installiere das neueste BIOS für dein {{board}}. Manche Mainboards brauchen ein Firmware-Update, bevor Windows die neuen Zertifikate schreiben kann.
3. Ändere die Secure-Boot-Schlüssel nicht von Hand, außer der Mainboard-Hersteller sagt es dir.

## So prüfst du die Behebung
Starte den Scan erneut als Administrator. KEK CA 2023 und Windows UEFI CA 2023 sollten „Vorhanden“ zeigen.
