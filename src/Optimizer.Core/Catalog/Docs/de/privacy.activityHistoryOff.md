# Aktivitätsverlauf aus

## Zusammenfassung
Verhindert, dass Windows deinen Aktivitätsverlauf (geöffnete Apps, Dateien und Webseiten) sammelt und hochlädt.

## So funktioniert es
Drei Richtlinien unter System schalten den Aktivitätsfeed sowie das Veröffentlichen und Hochladen von Benutzeraktivitäten ab [1].

## Warum es helfen kann
Weniger Protokollierung im Hintergrund. Kein messbarer Effekt auf die Leistung.

## Belege
Eine Datenschutzeinstellung ohne Effekt auf die FPS.

## Nachteile & Risiken
Funktionen, die den Aktivitätsverlauf nutzen (Weiterarbeiten auf anderen Geräten), funktionieren nicht mehr.

## Wann du es nicht nutzen solltest
Behalte ihn, wenn du geräteübergreifende Aktivitäten nutzt.
