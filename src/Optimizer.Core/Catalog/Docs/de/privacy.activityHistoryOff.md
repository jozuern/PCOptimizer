# Aktivitätsverlauf aus

## Zusammenfassung
Verhindert, dass Windows deinen Aktivitätsverlauf (geöffnete Apps, Dateien und Webseiten) auf diesem PC aufzeichnet.

## So funktioniert es
Drei Richtlinien unter System schalten den Aktivitätsfeed sowie das Veröffentlichen und Hochladen von Benutzeraktivitäten ab [1]. Der Schalter Einstellungen > Datenschutz und Sicherheit > Aktivitätsverlauf > „Meinen Aktivitätsverlauf auf diesem Gerät speichern“ ist dann aus und gesperrt.

## Warum es helfen kann
Weniger Protokollierung im Hintergrund. Ein Effekt auf die Leistung ist weder zu erwarten noch belegt.

## Belege
Eine Datenschutzeinstellung ohne Effekt auf die FPS.

## Nachteile & Risiken
Unter Windows 11 wird der Aktivitätsverlauf nur auf dem Gerät gespeichert; das Hochladen in die Cloud hat Microsoft im Januar 2024 entfernt [2]. Funktionen, die den lokalen Verlauf lesen, etwa Edge-Aktivitäten in Windows, haben ihn dann nicht mehr.

## Wann du es nicht nutzen solltest
Behalte ihn, wenn du eine Funktion nutzt, die den lokalen Aktivitätsverlauf braucht.
