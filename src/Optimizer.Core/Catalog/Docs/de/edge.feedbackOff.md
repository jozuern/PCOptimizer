# Microsoft Edge: kein Feedback-Werkzeug

## Zusammenfassung
Entfernt die Feedback-Funktion von Edge: keine Feedback-Aufforderungen oder Umfragen, und Edge kann keine Feedbackberichte senden.

## So funktioniert es
Edge nutzt seine Feedback-Funktion für Feedback, Vorschläge, Kundenumfragen und Problemberichte [1]. Mit der Richtlinie UserFeedbackAllowed auf aus lässt sich Edge-Feedback nicht mehr öffnen [1]. Sie gilt nach einem Neustart von Edge für alle Profile, auch mit Microsoft-Konto [1].

## Warum es helfen kann
Keine Umfrage-Aufforderungen, und es wird kein Feedback mit Screenshots oder Diagnosedaten aus Versehen gesendet. Eine Einstellung für Datenschutz oder Bedienung; sie ändert weder Bildrate noch Latenz.

## Belege
Eine von Microsoft beschriebene Edge-Richtlinie [1].

## Nachteile & Risiken
Du kannst Edge-Probleme nicht mehr direkt aus dem Browser an Microsoft melden. Weil es eine Richtlinie ist, zeigt Edge in Menü und Einstellungen an, dass es von deiner Organisation verwaltet wird, und der passende Schalter in den Edge-Einstellungen ist gesperrt. Rückgängig entfernt sie wieder.

## Wann du es nicht nutzen solltest
Wenn du Microsoft Feedback zu Edge schickst.
