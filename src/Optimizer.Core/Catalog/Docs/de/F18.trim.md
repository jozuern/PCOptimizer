# TRIM für SSDs abgeschaltet

## Zusammenfassung
::: status Problem
TRIM ist ausgeschaltet. Ohne TRIM erfährt eine SSD nicht, welche Daten gelöscht wurden, und die Schreibgeschwindigkeit kann mit der Zeit sinken.
:::
::: status Ok,Unknown,Info,Unsupported
Prüft, ob Windows TRIM-Befehle an SSDs sendet. Das hält ihre Schreibgeschwindigkeit hoch.
:::

## Warum das wichtig ist
Löschst du eine Datei, markiert Windows den Platz nur als frei. TRIM teilt der SSD mit, welche Blöcke nicht mehr gebraucht werden, damit sie sie im Hintergrund löschen kann. Ohne TRIM muss die SSD das bei späteren Schreibvorgängen erledigen. Das bremst Installationen und Spiele-Updates und erhöht den Verschleiß. Windows schaltet TRIM standardmäßig ein. Aus ist es meist nur, wenn ein Tweak-Tool oder eine alte Anleitung es deaktiviert hat.

## Wie wir es erkennen
Wir lesen `DisableDeleteNotification` unter `HKLM\SYSTEM\CurrentControlSet\Control\FileSystem`. Der Wert 0 bedeutet TRIM an, 1 bedeutet aus. Es ist derselbe Wert, den `fsutil behavior query DisableDeleteNotify` anzeigt.

## So behebst du es
1. Öffne ein Terminal als Administrator.
2. Führe `fsutil behavior set DisableDeleteNotify 0` aus.
3. Starte für jede SSD einmal **Laufwerke defragmentieren und optimieren**. Das sendet ein vollständiges Retrim.

Oder nutze **Beheben** oben in diesem Bereich: Die App nimmt die Änderung für dich vor und kann sie später rückgängig machen.

## So prüfst du die Behebung
Starte den Scan erneut. TRIM sollte als „An“ angezeigt werden.
