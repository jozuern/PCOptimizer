# Weniger Windows-Update-Benachrichtigungen

## Zusammenfassung
Schaltet Windows-Update-Benachrichtigungen bis auf Neustartwarnungen aus. Updates werden weiter wie bisher geladen und installiert. Pro, Enterprise und Education.

## So funktioniert es
Die Richtlinie für Windows-Update-Benachrichtigungen hat drei Stufen: 0 Standard, 1 alle Benachrichtigungen außer Neustartwarnungen aus, 2 alle aus, auch Neustartwarnungen [1]. Die App setzt 1 [1]. Die Richtlinie ändert nicht, wie und wann Updates geladen und installiert werden [1].

## Warum es helfen kann
Weniger Einblendungen zu Updates beim Arbeiten oder Spielen, und du erfährst trotzdem von einem anstehenden Neustart.

## Belege
Eine von Microsoft beschriebene Windows-Richtlinie [1]. Microsoft warnt: Ohne Benachrichtigungen und ohne automatische Updates fallen fehlende Sicherheitsupdates niemandem auf [1]; die automatischen Updates bleiben hier an.

## Nachteile & Risiken
Von neuen Updates erfährst du nur unter Einstellungen > Windows Update oder durch die Neustartwarnung.

## Wann du es nicht nutzen solltest
Wenn du automatische Updates ausgeschaltet hast; dann brauchst du die Benachrichtigungen.
