# Teilen von Handschriftdaten aus

## Zusammenfassung
Verhindert, dass Windows Handschriftproben und Fehlerberichte der Handschrifterkennung an Microsoft sendet.

## So funktioniert es
Zwei Richtlinien schalten das Teilen von Personalisierungsdaten der Handschrift und die Fehlerberichte der Handschrifterkennung ab [1].

## Warum es helfen kann
Weniger Daten verlassen diesen PC. Kein messbarer Einfluss auf die Leistung.

## Belege
Datenschutzeinstellung; sie ändert weder Bildrate noch Latenz.

## Nachteile & Risiken
Ohne Stift keine.

## Wann du es nicht nutzen solltest
Wenn du helfen willst, die Handschrifterkennung zu verbessern.
