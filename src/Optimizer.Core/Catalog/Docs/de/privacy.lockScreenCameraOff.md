# Keine Kamera auf dem Sperrbildschirm

## Zusammenfassung
Niemand kann die Kamera vom Sperrbildschirm aus öffnen, und der Schalter dafür in den Einstellungen ist gesperrt. Pro, Enterprise und Education.

## So funktioniert es
Die Richtlinie "Aktivieren der Kamera auf dem Sperrbildschirm verhindern" (NoLockScreenCamera = 1) sperrt den Schalter für die Sperrbildschirmkamera in den Einstellungen und verhindert, dass auf dem Sperrbildschirm eine Kamera gestartet wird [1].

## Warum es helfen kann
Jemand an deinem gesperrten PC kann die Kamera nicht nutzen.

## Belege
Eine von Microsoft beschriebene Windows-Richtlinie [1]. Eine Datenschutzeinstellung ohne Einfluss auf Bildrate oder Latenz.

## Nachteile & Risiken
Kein schnelles Foto vom Sperrbildschirm aus; die meisten Desktop-PCs bieten das ohnehin nicht.

## Wann du es nicht nutzen solltest
Wenn du auf einem Tablet die Kamera vom Sperrbildschirm aus nutzt.
