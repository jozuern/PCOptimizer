# Druckwarteschlange auf Manuell

## Zusammenfassung
Lässt die Druckwarteschlange bei Bedarf starten. Wird nur angeboten, wenn kein Drucker installiert ist.

## So funktioniert es
Der Dienst Druckwarteschlange wird auf Manuell gestellt [1]. Windows startet ihn, wenn du druckst oder einen Drucker hinzufügst.

## Warum es helfen kann
Ein dauerhaft laufender Dienst weniger; die Druckwarteschlange hatte außerdem mehrere Sicherheitsprobleme.

## Belege
Kein messbarer Einfluss auf die Bildrate.

## Nachteile & Risiken
Der erste Druckauftrag oder „Print to PDF“ nach dem Start dauert einen Moment länger.

## Wann du es nicht nutzen solltest
Wenn du oft druckst.
