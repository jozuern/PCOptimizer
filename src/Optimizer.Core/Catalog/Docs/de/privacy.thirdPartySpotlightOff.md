# Windows-Blickpunkt: keine Vorschläge von Drittanbietern

## Zusammenfassung
Blickpunkt, Start und Windows-Tipps schlagen keine Apps und Inhalte anderer Firmen mehr vor. Die Blickpunkt-Bilder bleiben. Pro, Enterprise und Education.

## So funktioniert es
Die Benutzerrichtlinie "Keine Drittanbieterinhalte in Windows-Blickpunkt vorschlagen" (DisableThirdPartySuggestions = 1) beendet Vorschläge für Apps und Inhalte von Drittanbietern in Blickpunkt-Funktionen wie dem Sperrbildschirm, vorgeschlagenen Apps in Start und Windows-Tipps; Vorschläge für Microsoft-Funktionen, -Apps und -Dienste können weiter erscheinen [1]. Microsoft führt sie für Pro, Enterprise und Education [1].

## Warum es helfen kann
Weniger Werbung auf dem Sperrbildschirm und in Windows. Eine Datenschutzeinstellung ohne Einfluss auf Bildrate oder Latenz.

## Belege
Eine von Microsoft beschriebene Windows-Richtlinie [1].

## Nachteile & Risiken
Keine, außer dass diese Vorschläge fehlen.

## Wann du es nicht nutzen solltest
Wenn du App-Vorschläge anderer Firmen magst.
