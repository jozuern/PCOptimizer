# Brave: keine Produktanalyse, kein Nutzungs-Ping, kein Web Discovery

## Zusammenfassung
Brave sendet keine datenschutzfreundliche Produktanalyse, keinen täglichen Nutzungs-Ping und keine Web-Discovery-Daten für Brave Search mehr.

## So funktioniert es
Drei Brave-Richtlinien [1]: BraveP3AEnabled auf 0 beendet die anonyme Produktanalyse (P3A); BraveStatsPingEnabled auf 0 beendet den kleinen Ping, mit dem aktive Nutzer gezählt werden; BraveWebDiscoveryEnabled auf 0 hält das Web Discovery Project aus, das Daten für den Index von Brave Search beisteuert [1]. Sie brauchen Brave 1.83 oder neuer [1].

## Warum es helfen kann
Weniger Daten verlassen den PC, auch wenn Brave sie als anonym beschreibt. Bildrate und Latenz ändern sich nicht.

## Belege
Von Brave beschriebene Richtlinien [1].

## Nachteile & Risiken
Brave bekommt weniger Nutzungszahlen, um den Browser zu verbessern. Weil es Richtlinien sind, zeigt Brave im Menü "Von deiner Organisation verwaltet", und brave://policy listet sie auf. Rückgängig entfernt sie.

## Wann du es nicht nutzen solltest
Wenn du Brave mit anonymen Nutzungsdaten unterstützen willst.
