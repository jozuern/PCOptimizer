# Monitor am Mainboard statt an der Grafikkarte

## Zusammenfassung
::: status Problem
{{displays}} steckt am Mainboard. Dadurch steuert die integrierte Grafik des Prozessors den Monitor statt der {{dgpu}}.
:::
::: status Info
{{displays}} steckt am Mainboard. Dein Hauptmonitor hängt an der {{dgpu}}, das spielt also nur eine Rolle, wenn du auf diesem Monitor spielst.
:::
::: status Ok
Jeder Monitor steckt an der Grafikkarte.
:::
::: status Unknown,Unsupported
Prüft, ob an einem Desktop-PC der Hauptmonitor an der Grafikkarte steckt und nicht am Mainboard.
:::

## Warum das wichtig ist
Die Bildausgänge am Mainboard gehören zur integrierten Grafik im Prozessor. Ein Monitor dort wird von dieser GPU angesteuert. Windows kann Spiele zwar trotzdem auf der Grafikkarte berechnen, dann muss aber jedes fertige Bild zur Anzeige an die integrierte Grafik weitergereicht werden, so wie NVIDIA es für Laptops mit Optimus beschreibt [1]. Das kostet Leistung und Verzögerung, und welche Bildwiederholraten und welche variable Bildwiederholrate (G-SYNC, FreeSync) du nutzen kannst, hängt dann vom Mainboard-Ausgang und der integrierten Grafik ab. Bei Desktops mit Grafikkarte gehört das Kabel des Monitors, auf dem du spielst, in die Ausgänge der Karte.
::: variant secondary
Ein zweiter Monitor am Mainboard kann Absicht sein, zum Beispiel für Chat oder eine Stream-Vorschau. Spiele auf dem Hauptmonitor betrifft das nicht.
:::

## Wie wir es erkennen
Für jede aktive Anzeige lesen wir, welcher Grafikadapter sie ansteuert (Windows-Anzeigekonfiguration), und vergleichen ihn mit der Liste der GPUs. Ein Adapter gilt als integriert, wenn sein Name zu den Mustern im Katalog passt, zum Beispiel Intel UHD Graphics oder AMD Radeon Graphics ohne RX-Modellnummer. Nur die Hauptanzeige (die am Ursprung des Desktops) zählt als Problem, weitere Anzeigen an der integrierten Grafik sind eine Information. Können wir eine Anzeige keinem Adapter zuordnen, ist das Ergebnis unbekannt. Eingebaute Bildschirme von All-in-One-PCs bewerten wir nicht, weil ihre Verkabelung fest ist.

## So behebst du es
::: status Problem,Info
1. Fahre den PC herunter.
2. Stecke das Monitorkabel von den Ausgängen am Mainboard (Anschlussblende neben den USB-Ports) an einen Ausgang der Grafikkarte (meist weiter unten, waagerecht nebeneinander).
3. Starte den PC. Bleibt das Bild schwarz, schließe das Kabel zuerst an die Grafikkarte an und prüfe dann im BIOS, ob die primäre Anzeige auf die PCIe-Grafikkarte eingestellt ist. Nutzt dein Systemlaufwerk BitLocker, setze es aus, bevor du BIOS-Einstellungen änderst, sonst fragt Windows beim nächsten Start womöglich nach dem Wiederherstellungsschlüssel [2].
:::
::: status Ok,Unknown,Unsupported
Nichts zu tun.
:::

## So prüfst du die Behebung
Starte den Scan erneut. Bei jeder Anzeige, auf der du spielst, sollte unter „Angeschlossen an“ deine Grafikkarte stehen.
