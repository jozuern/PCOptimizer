# Variable Bildwiederholrate (G-SYNC, FreeSync)

## Zusammenfassung
::: variant off
{{display}} unterstützt variable Bildwiederholrate, aber G-SYNC ist aus. Eingeschaltet verschwinden Tearing und Ruckler ohne die Verzögerung von V-Sync.
:::
::: variant on
G-SYNC ist für {{display}} eingeschaltet.
:::
::: variant notPossible
{{display}} sieht nach einem Monitor mit variabler Bildwiederholrate aus, der Treiber meldet sie aber als nicht möglich. Meist liegt es am Anschluss oder an einer Monitoreinstellung.
:::
::: variant fixed
{{display}} unterstützt keine variable Bildwiederholrate.
:::
::: variant nvidiaUnknown,otherVendor
{{display}} sieht nach einem Monitor mit variabler Bildwiederholrate aus. Für diese Grafikkarte können wir die Einstellung nicht lesen, prüfe sie im Treiber.
:::

## Warum das wichtig ist
Mit fester Bildwiederholrate reißt ein Bild, das nicht rechtzeitig fertig ist (V-Sync aus), oder es wartet auf den nächsten Bildwechsel (V-Sync an). Das erzeugt Ruckler und Verzögerung. Mit variabler Bildwiederholrate (VRR) wartet stattdessen der Monitor innerhalb seines Bereichs auf die Grafikkarte. Einbrüche der Bildrate wirken dann deutlich flüssiger, ohne die Verzögerung von V-Sync.

## Wie wir es erkennen
::: variant off,on,notPossible,fixed
Wir lesen den VRR-Status des Bildschirms über NVIDIAs Treiberschnittstelle (NVAPI): ob VRR an diesem Bildschirm und Anschluss möglich ist und ob G-SYNC eingeschaltet ist.
:::
::: variant nvidiaUnknown,otherVendor
Der Treiber dieser Grafikkarte hat keine Schnittstelle, die wir lesen können. Daher nutzen wir die EDID-Daten des Monitors, und das Ergebnis ist nur eine Information: Ein weiter Frequenzbereich (zum Beispiel 48 Hz bis 144 Hz) mit Unterstützung für stufenlose Frequenzen ist typisch für VRR-Monitore. Das ist ein Hinweis, kein Beweis.
:::

## So behebst du es
::: variant off
1. Öffne **NVIDIA-Systemsteuerung > Anzeige > G-SYNC einrichten**.
2. Setze den Haken bei **G-SYNC, G-SYNC Compatible aktivieren**, wähle Vollbild oder Vollbild und Fenster, wähle {{display}} und setze den Haken bei **Einstellungen für das ausgewählte Anzeigemodell aktivieren**.
3. Häufig empfohlen mit G-SYNC, gestützt auf die Latenztests von Blur Busters (eine unabhängige Testseite): Stelle unter 3D-Einstellungen verwalten **Vertikale Synchronisierung = Ein** ein und setze ein Bildratenlimit mindestens 3 FPS unter der Bildwiederholrate [1].
:::
::: variant notPossible
1. Schalte im Menü des Monitors **FreeSync** oder **Adaptive-Sync** ein.
::: if hdmi
2. Nutze **DisplayPort**, wenn der Monitor das hat. G-SYNC Compatible über HDMI braucht einen Bildschirm mit HDMI-VRR und eine GeForce GTX 16 oder RTX [3].
:::
3. Aktualisiere den Grafiktreiber und starte den Scan erneut.
4. Steht der Monitor nicht auf NVIDIAs Liste geprüfter Bildschirme, kann G-SYNC Compatible trotzdem funktionieren, muss aber von Hand eingeschaltet werden [2].
:::
::: variant otherVendor
Die Menünamen unten können sich je nach Treiberversion unterscheiden.
::: if amd
1. Öffne **AMD Software: Adrenalin Edition > Gaming > Anzeige** und schalte **AMD FreeSync** für diesen Bildschirm ein.
:::
::: if intel
1. Öffne **Intel Graphics Software > Anzeige** und schalte **Adaptive Sync** ein (bei Arc-Karten und unterstützter integrierter Grafik).
:::
1. Schalte FreeSync oder Adaptive-Sync auch im Menü des Monitors ein.
:::
::: variant nvidiaUnknown
1. Öffne **NVIDIA-Systemsteuerung > Anzeige > G-SYNC einrichten** und prüfe, ob G-SYNC für diesen Bildschirm angeboten wird.
:::
::: variant on,fixed
Nichts zu tun.
:::

## So prüfst du die Behebung
Starte den Scan erneut. Mit der G-SYNC-Anzeige (NVIDIA-Systemsteuerung > Anzeige > G-SYNC Compatible-Anzeige) siehst du im Spiel, dass es wirkt.
