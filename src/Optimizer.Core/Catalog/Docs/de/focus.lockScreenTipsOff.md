# Sperrbildschirm: keine Fakten und Tipps

## Zusammenfassung
Schaltet "Unterhaltsame Fakten, Tipps, Tricks und mehr auf dem Sperrbildschirm" ab. Stellt einen Sperrbildschirm mit Windows-Blickpunkt dabei auf Bild um.

## So funktioniert es
Mit einem Bild oder einer Diashow als Sperrbildschirm-Hintergrund fügt die Option "Unterhaltsame Fakten, Tipps, Tricks und mehr auf dem Sperrbildschirm" Inhalte von Microsoft hinzu [1]. Die Option gibt es nur bei Bild oder Diashow [2]. Die App setzt RotatingLockScreenOverlayEnabled und SubscribedContent-338387Enabled auf 0. Microsoft dokumentiert den Registry-Wert hinter dem Schalter nicht; die Anleitung [2] zeigt den Wert, den der Schalter schreibt. Ein Test unter echtem Windows 11 26H2 hat die Nebenwirkung unten gezeigt, daher bleibt die Option eine Vorschau.

## Warum es helfen kann
Ein ruhigerer Sperrbildschirm ohne Inhalte von Microsoft.

## Belege
Eine persönliche Vorliebe ohne Einfluss auf Bildrate oder Latenz.

## Nachteile & Risiken
In einem Test unter Windows 11 26H2 hat die Änderung den Sperrbildschirm außerdem von Windows-Blickpunkt auf Bild umgestellt; Rückgängig machen hat Windows-Blickpunkt wieder eingeschaltet.

## Wann du es nicht nutzen solltest
Wenn dir die Tipps auf dem Sperrbildschirm gefallen oder du Windows-Blickpunkt nutzt.
