# Ryzen X3D mit zwei Chiplets: Energiesparplan

## Zusammenfassung
::: status Problem
Dein Ryzen X3D hat 3D V-Cache auf nur einem von zwei Chiplets. Der aktive Plan ist nicht „Ausbalanciert“, deshalb landen Spiele womöglich auf dem Chiplet ohne Zusatz-Cache.
:::
::: status Ok,Unknown,Info,Unsupported
Dein Ryzen X3D hat 3D V-Cache auf einem von zwei Chiplets. „Ausbalanciert“ ist aktiv. Das braucht der AMD-Treiber, um Spiele auf dem V-Cache-Chiplet zu halten.
:::

## Warum das wichtig ist
Bei diesen Prozessoren hat nur ein Chiplet (CCD) den großen gestapelten L3-Cache, der X3D-Chips in Spielen schnell macht. Der AMD-Chipsatztreiber („3D V-Cache Performance Optimizer“) und die Xbox Game Bar erkennen ein laufendes Spiel und parken die Kerne des anderen Chiplets. So läuft das Spiel auf dem Cache-Chiplet. Das funktioniert nur mit Core Parking im Plan **Ausbalanciert**. „Höchstleistung“, „Ultimative Leistung“ oder Tools, die Core Parking abschalten, setzen den Mechanismus außer Kraft. Spiele verteilen sich dann auf beide Chiplets und laufen mit weniger und unruhigeren FPS.

## Wie wir es erkennen
Wir lesen den Cache-Aufbau des Prozessors aus Windows: Zwei L3-Cache-Bereiche mit deutlich unterschiedlicher Größe (der größere mindestens doppelt so groß) bedeuten ein Chiplet mit V-Cache. Die Modellliste im Katalog bestätigt bekannte Modelle. Dann lesen wir den Typ des aktiven Energiesparplans.

## So behebst du es
1. Wähle den Plan **Ausbalanciert** (Einstellungen > System > Energie).
2. Installiere den aktuellen AMD-Chipsatztreiber von amd.com (er enthält den V-Cache-Optimizer).
3. Lass die Xbox Game Bar installiert und aktuell. Entferne sie nicht mit Debloat-Tools.
4. Lass im BIOS **CPPC Dynamic Preferred Cores** auf **Auto** oder **Driver**.

## So prüfst du die Behebung
Starte den Scan erneut. Während eines Spiels sollte der Task-Manager die Last vor allem auf der ersten Hälfte der Kerne zeigen.
